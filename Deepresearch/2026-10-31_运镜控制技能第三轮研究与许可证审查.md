## 二、补充的控制技术路线

### 1. 参考视频重拍
ReCamMaster / ReDirector：输入原视频和目标相机运动条件，生成沿新轨迹观察同一内容的视频。价值是保留原视频中的动作/场景变化，再改变摄影机视角。限制是模型对动态主体、遮挡和新视点的重建能力。

### 2. RGB-D 几何联合控制
DualCamCtrl / VerseCrafter：不只控制相机轨迹，还通过深度或 4D 场景状态提高几何一致性。适用于大位移、主体交互和多物体运动，但计算成本明显高于普通 I2V。

### 3. 角色大角度环绕
WorldCast：单图并不足以支撑真实 360° 人物环绕；需要补充 1–4 张不同视角主体锚点。轨迹控制和身份保持由不同条件共同承担。这是此前技能中“单张图不能承诺完整环绕”规则的进一步工程化路径。

### 4. 轨迹类别与参数
ReCamMaster/ReDirector 的十类基础轨迹可作为教学入门集，但不应把 Zoom 与 Dolly 混为一谈；项目中的“Zoom In/Out”命名是其模型轨迹预设，不代表真实摄影机物理机制完全等价。导演执行单仍应区分焦距变化与机位平移。

## 三、商业使用风险分级

- **可作为商业项目候选依赖（仍须检查权重、数据和基础模型各自条款）**：MIT/Apache 项目，例如 ReCamMaster、ReDirector、SCoPE、OmniCamera、GEN3C、WorldCast、Emulsion、Atlas Camera Studio。
- **仅供研究，不得用于商业制作**：AC3D（Snap 明确 non-commercial research only）、VerseCrafter（仅学术用途；禁止商业/生产用途；限制欧盟使用）。
- **暂不复制/集成代码**：DualCamCtrl、CameraAnything、TriMotion、TrajectoryCrafter、Generate-Camera-Trajectory 等本轮未核实根目录许可证的项目。
- **许可证不等于模型权重许可**：必须单独检查底座模型、训练数据、第三方依赖、服务 API 和生成内容条款。

## 四、对运镜 Skill 的最终影响

将工具分为四层：
1. 导演决策层：镜头动机、动态合同、运动预算、景别/焦段/轴线；
2. 轨迹表达层：自然语言、关键帧、位姿矩阵、参考视频、相机视锥参考；
3. 几何支撑层：深度、点云、3DGS、多视角锚点、4D 场景；
4. 生成执行层：I2V/T2V/V2V 模型和相机条件注入。

以后任何“运镜已控制”的说法必须注明使用了哪一层条件。只有提示词不能宣称逐帧轨迹控制；只有轨迹文件也不能宣称模型忠实执行，必须检查生成结果。
