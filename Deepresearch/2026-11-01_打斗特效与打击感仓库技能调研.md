# 打斗特效与打击感技能仓库调研

日期：2026-11-01  
目标：为 AIGC 漫剧仓库建立打斗动作、受击反馈、冲击特效、速度表现、剪辑节奏和后期合成的可复用能力。

## 一、研究结论

打击感不是单独的特效层。有效链路必须连起来：

**动作因果与身体/武器受力 → 接触证明 → 受击者状态变化 → 环境反馈 → 视觉特效 → 声音/剪辑峰值 → 衰减和恢复。**

若动作没有真实接触，增加火花、白闪、冲击环和震屏只会放大假感。若特效没有来源、路径、遮挡和消散，画面会像贴纸或素材包叠加。

本轮按四层整理：
1. 动作导演和打斗因果；
2. 身体/武器物理与受击响应；
3. VFX 生命周期、媒介适配与特效层级；
4. 冲击帧、hit-stop、声音和后期合成。

### C. 动作节奏与 VFX 机制

- 动作节奏：起势、加速、接触峰值、受击响应、拖尾、制动和恢复；节奏必须服从动作物理。
- 交锋密度：以关系变化衡量，不以每秒挥拳次数衡量；有效变化包括距离、角度、平衡、武器线、主动权和环境。
- VFX 因果：来源/触发、形成、路径、作用对象、受击与环境响应、峰值、衰减/残留。
- 媒介适配：纯 2D 重点是剪影、smear、手绘冲击帧和方向性碎片；2.5D 重点是分层深度与遮挡；写实 CG 重点是材质、惯性、碎屑和光照；混合媒介必须统一帧率、黑位、方向与光线。
- 声画同步：接触瞬态、身体响应、环境回响和尾音应分层；声音峰值以实际接触时刻为锚点。

## 三、打击感最常见的失败机制

1. 隔空挥拳却出现巨大爆炸：接触关系缺失。
2. 受击者提前后仰：时间因果颠倒。
3. 命中无重量：没有受击位移、失衡、脚步或武器线变化。
4. 重武器像泡沫：没有惯性、拖尾、制动和恢复。
5. 火花/闪光无来源：没有明确发射点、材质和碰撞方向。
6. 冲击波像贴纸：没有深度、遮挡和空间交互。
7. 碎片漂浮穿模：没有发射速度、重力、碰撞和沉降。
8. 全程抖屏：摄影机没有受力触发与衰减。
9. 每次打击同一个效果：缺少轻/中/重事件预算。
10. 特效遮住人物脸、手、武器和接触点：视觉层级失控。
11. 音效提前或滞后：没有绑定接触时间轴。
12. 下一镜伤势、武器损坏和环境裂纹重置：跨镜状态未继承。
