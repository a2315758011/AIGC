# 运镜控制技能第二轮扩展研究

日期：2026-10-31  
目标仓库：`a2315758011/AIGC`  
研究对象：AI 导演 Skill、三维摄影机轨迹工具、可控视频生成研究代码。  
范围说明：本轮是扩展检索和分层审查，不宣称穷尽全网。

## 一、结论先行

上一轮偏重自然语言提示词技能，遗漏了导演全流程、3D 预演和真实相机条件控制三类重要能力。本轮将搜集范围扩展为：
1. 导演/摄影指导 Agent Skill；
2. 三维相机路径编辑与镜头预演；
3. 相机位姿/参考视频/文本/深度/多视角条件的视频生成模型；
4. 从参考视频反求相机运动的工具。

## 二、优先级最高的可迁移项目

### A. 导演级 Skill
- [wuwangzhang1216/DirectorSKILL](https://github.com/wuwangzhang1216/DirectorSKILL)：v2.1.0，MIT。13 步导演流程、分镜/调度/视频提示词、20 种风格模块、工具能力适配、故障码和修复闭环。重点采纳镜头动机、运动预算、首帧控制点、失败诊断、镜头时间变化；不复制完整技能，避免覆盖本仓库现有分镜主规则。
- [olegspiridonovdev-spec/cinematic-video-skill](https://github.com/olegspiridonovdev-spec/cinematic-video-skill)：MIT。强调单镜头单主运动、动作头/转折/尾、镜头动机、运动预算、真实视频抽帧审片。其 12 块提示词合同较长，不强制照搬，按任务压缩使用。
- [dennisonbertram/emulsion](https://github.com/dennisonbertram/emulsion)：MIT。Three.js 分镜预演应用 + Agent Skill；人物/物体关键帧、摄影机位置/LookAt/FOV、跟随、轨迹参考 MP4、shots/sets/assets。技能文档描述了相机关键帧配方和 QA 方法。
- [cajias/agentic-video-skills](https://github.com/cajias/agentic-video-skills)：包含 cinematic-director 技能，MIT。与 DirectorSKILL 有明显谱系/结构相似性，先作为同源版本对照，不重复纳入多个重复技能。
- [HiAPIAI/hiapi-image-to-video-camera-motion-skill](https://github.com/HiAPIAI/hiapi-image-to-video-camera-motion-skill)：专业 I2V 运镜技能，读取 SKILL、motion language、source image analysis、prompt recipes、model routing、validator。根目录 LICENSE 未能确认，本次仅研究，不复制正文。

### B. 轨迹与预演工具
- [Generate-Camera-Trajectory](https://github.com/mbkizil/Generate-Camera-Trajectory)：可视化单镜头轨迹、参数化运动原语、随机批量采样、相机 POV 预览、JSON 配方、NPZ 位姿导出，覆盖 OpenGL/Blender/OpenCV/COLMAP。吸收可复现轨迹设计和坐标系声明。
- [Emulsion](https://github.com/dennisonbertram/emulsion)：使用三维代理人和场景物体预演站位与摄影机关键帧，并导出运动参考视频；MIT。优先作为可选预演工具研究。
- [Atlas Camera Studio](https://github.com/worldlabsai/atlas-camera-studio)：MIT，React/Three.js + World Labs Marble API；从单图深度重建点云，绘制相机路径、平滑、插值并生成短视频。API 需授权并按服务计费。
- [CameraPath-Lab](https://github.com/Kayariyan28/CameraPath-Lab)：从视频恢复相机位置/旋转/时序/速度/FOV与切点，导出 Blender 中性运动参考；v0.1.0，早期版本，macOS Apple Silicon 定位，不适合作为 Windows 直接部署目标。
- [mbkizil/Generate-Camera-Trajectory](https://github.com/mbkizil/Generate-Camera-Trajectory)：其 README 引用 LAMP/Auteur DSL；本次未找到根目录 LICENSE，记录为研究参考，不复制代码。

### C. 真实可控视频生成
- [TencentARC/SCoPE](https://github.com/TencentARC/SCoPE)：Apache-2.0。输入首帧、文本、逐帧 OpenCV camera-to-world pose 和 HFOV；使用 camera sightline/Plücker ray 条件控制视频，支持相机视锥 HUD。适合将文字运镜转成位姿轨迹。
- [Yukun66/OmniCamera](https://github.com/Yukun66/OmniCamera)：Apache-2.0。相机条件（文字、轨迹、参考相机视频）与内容条件（文字、图片、视频）组合；README 明确公开 checkpoint 是早期版本，结果可能不同于论文演示。
- [gulucaptain/CameraNoise](https://github.com/gulucaptain/CameraNoise)：README 标示 Apache-2.0。将参考视频相机位姿转成 GRFlow 与 CameraNoise 条件，可单独构建条件或进行 Wan2.1 I2V；依赖 CUDA、权重和较大算力。
- [nv-tlabs/GEN3C](https://github.com/nv-tlabs/GEN3C)：Apache-2.0。3D-informed 视频生成，显式支持 left/right/up/down/zoom/clockwise/counterclockwise、相机旋转模式和位移距离。官方说明主要在 H100/A100 测试，完整 offload 峰值仍约 43GB。
- [yixuanli98/CameraAnything](https://github.com/yixuanli98/CameraAnything)：Wan2.1 基础；联合控制相机外参（视点/轨迹/多镜头切换）和内参（焦距/分辨率/画幅）。本次未找到 LICENSE，不复制代码。
- [seunghyuns98/TriMotion](https://github.com/seunghyuns98/TriMotion)：ECCV 2026；视频/Pose/文本三模态轨迹嵌入对齐，136K triplets，支持 I2V/V2V。依赖 Wan2.1 与额外权重；本次未确认 LICENSE。
- [TrajectoryCrafter](https://github.com/TrajectoryCrafter/TrajectoryCrafter)：ICCV 2025 Oral；根据目标相机轨迹重拍单目视频。官方说明复杂场景会受基础视频扩散模型能力限制；本次未确认 LICENSE。
- [WorldinWorld](https://github.com/Westlake-AGI-Lab/WorldinWorld)：自由相机重摄影、bullet time、视频编辑；通过深度/几何 warp 提供新视点条件。需要高显存世界模型。
- [PixCtrol/WorldCast](https://github.com/PixCtrol/WorldCast)：2026-10-23 发布推理代码，10-28 发布权重；单图 + 目标轨迹 + 1–4 张多视角主体锚点，针对大角度相机控制与身份保持。项目很新，许可证及训练/数据开放状态需继续核实。
- [TencentARC/VerseCrafter](https://github.com/TencentARC/VerseCrafter)：CVPR 2026，4D 相机与多物体轨迹联合控制，基于 Wan2.1 GeoAdapter；适合相机与角色动作同步研究。
- [cvlab-kaist/Vid-CamEdit](https://github.com/cvlab-kaist/Vid-CamEdit)：根据估计几何对输入视频进行目标相机轨迹编辑；代码、依赖和许可证需进一步核实。
- [Iron-LYK/ReCamDriving](https://github.com/Iron-LYK/ReCamDriving)：LiDAR-free 驾驶视频新轨迹控制，结合 3DGS；领域特化，不作为通用漫剧生成方案。
