# 多宫格视觉分镜联系表 Skill

版本：1.0.0 beta

面向 AI 漫剧、真人短剧、广告和动画的 4格/9格/12格/25格视觉分镜联系表。它是**分镜导演技能的生产编排层**，不替代上游剧本导演、场景真实性或正式漫画制作规则。

## 使用

将 `storyboard-contact-sheet-cn` 目录作为 Skill 提供给 AI 客户端。用户只需说明制作 4格、9格、12格或25格联系表，并提供剧本/广告脚本及已有角色、场景参考（若工程中已有，则自动恢复，不重复索要）。

Skill 会先读取现有分镜导演规则，按媒介调用真人安全分镜或漫画制作技能，再执行独立画格生产、逐格审核、manifest 校验和程序排版。

## 依赖

- Python 3.11+
- Pillow（见仓库工具目录 requirements.txt）
- 可用的图像生成能力；默认优先 GPT 原生生图，其他模型遵守工作站共享 Generation Gateway 规则。

## 工具入口

[多宫格联系表排版工具](../../tools/storyboard-contact-sheet/README.md)

支持：2×2、3×3、3×4、4×3、5×5。程序只排版，不创造剧情事实，不替代视觉审片。

## 当前验证状态

- 排版工具 CI：13 项排版器回归已通过，5 项 Skill 合同测试已通过，包含 25 格样本、中文标签、路径与文件保护。
- 后续新增 CLI 生成测试已提交，等待本轮 CI 确认。
- GPT 原生生图仍输出整张联系表的对照样本；独立画格一致性与真实项目端到端验收尚未通过。
- 本 Skill 处于 beta，不能标记为生产级完成。

## 核心原则

独立镜头先生成，联系表后排版；程序负责准确文字和布局，导演 Skill 负责剧情、人物、场景和镜头事实，独立验收负责连续性。不能用一张生成宫格图替代逐格生产。
