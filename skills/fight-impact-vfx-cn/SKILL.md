# 打斗与打击感特效导演

## 目标

把打斗设计成**动作可信、命中可读、力量可见、特效有因果、节奏有峰值、跨镜状态连续**的可执行视频方案。

本技能不是“加粒子、加闪光、加抖屏”的装饰器。打击感必须由动作路径、接触关系、受击响应、环境反馈、节奏和声音共同建立。

## 职责边界

- 本技能负责：打斗动作因果、受力可读性、打击节奏、命中特效、速度表现、环境破坏、声画同步、特效合成审查。
- storyboard-director-cn 负责分镜结构、景别与人物调度；需要时联读站位规则。
- camera-motion-director-cn 负责摄影机轨迹、运动方向和运镜可行性。
- 本技能不重写用户锁定的剧情、胜负、角色身份、武器、场景和动作顺序。
- 不提供现实伤害操作教学；只设计虚构影视表演、动画动作和视觉效果。

## 核心原则

1. **先有接触与受力，再有特效。** 火花、闪光、震屏不能替代真实可见的接触、格挡、擦身或明确近失误。
2. **每个重点命中必须改变状态。** 至少改变受击者的平衡、姿态、位置、方向、武器线、呼吸/表情或环境状态之一；决定性重击通常改变多个状态。
3. **力量沿路径传播。** 从支撑/发力源，经身体或武器，到接触点，再传给受击者和环境；不能让身体、武器、衣物、碎片各自无关地漂动。
4. **速度靠对比，不靠全程加速。** 清楚的预备、突然加速、短峰值、延迟拖尾、制动和恢复，比全程高速更有重量。
5. **特效必须有归属。** 每种效果要有来源、触发条件、方向、空间层级、碰撞对象和消散方式。
6. **一拍一个主视觉重点。** 命中点、武器轨迹、受击轮廓、环境破坏只能有一个主读点；次级效果不能抢主读点。
7. **特效不能遮住证明。** 观众必须看清谁命中谁、命中哪里、力量朝哪边传递、结果是什么。
8. **材质决定反馈。** 金属碰撞、布料抽动、木材断裂、石材崩裂、护甲受力、能量屏障不能套用同一套火花爆炸。
9. **效果分级。** 普通擦碰、有效命中、决定性重击分开配置；不是每次接触都上冲击波、白闪、镜头震动。
10. **生成能力如实声明。** 文本提示词只能表达意图，不能保证逐帧命中或后期合成；真实效果必须通过生成视频或合成结果验收。

## 执行流程

### 1. 锁定动作事实

从剧本、分镜、角色图、场景图和参考视频提取：
- 角色数量、身份、体型与动作能力；
- 武器形制、长度、重量分布、握持状态；
- 双方起始位置、朝向、距离、支撑脚和攻击线；
- 打斗目标、主动权变化、关键命中和结尾状态；
- 画风：写实、风格化 3D、2.5D、纯 2D 或混合媒介。

区分已知、画面可见、合理推断和未知。不能凭空补出隐藏视角、接触位置或物理结构。

### 2. 设计动作因果

每个交锋按可见动作编排：
- 发起者如何进入有效距离；
- 攻击路径、方向、速度和目标；
- 对手如何格挡、闪避、偏转、承受或反击；
- 是否真的接触，接触点在哪里；
- 接触后身体、武器、衣物、地面和环境如何响应；
- 双方新位置、朝向、平衡和主动权；
- 下一动作如何由新状态自然产生。

如果动作只有“打、躲、反击、连招”，但没有距离变化、接触证明和状态变化，先修动作，不要加特效掩盖。

### 3. 建立打击节奏

核心节奏：

~~~text
起势/压缩 → 承诺加速 → 接触/擦身/格挡 → 受击与环境响应 → 拖尾 → 制动/恢复
~~~

- 轻快拳脚：短预备、快速峰值、短恢复。
- 中等兵器：明确预备、快速接触、可读的回收。
- 重型武器：较长蓄势、承诺式加速、明显惯性拖尾和刹车。
- 柔性/链状武器：手柄先动、末端延迟到达、张力回弹。
- 超高速动作：允许压缩起势，但必须通过地面摩擦、空气尾流、落地、滑步或主动制动证明速度。

不要给每次动作强塞精确毫秒数。只有真实音轨、动画帧、动捕或预演时钟支持时才使用精确时间码。

### 4. 选择命中反馈等级

| 等级 | 典型事件 | 反馈策略 |
|---|---|---|
| L1 擦碰/试探 | 轻触、格挡、擦身 | 局部衣料/武器微振、短促声响、微小姿态修正 |
| L2 有效命中 | 清晰击中、被迫退步 | 接触点压缩或偏转、受击位移、短促环境反馈 |
| L3 决定性重击 | 破防、击飞、重武器砸击 | 明确接触峰值、强受力链、明显位移、材质破坏或空气/尘土冲击、短促镜头响应 |
| L4 超常/能量事件 | 能量爆发、巨大碰撞、法术冲击 | 明确能量源、传播路径、作用范围、目标响应和残留状态；不能只用全屏白闪 |

等级是导演分配预算，不是固定粒子数量或物理测量值。

### 5. 设计特效因果链

重要特效按以下顺序设计：

~~~text
来源/触发 → 形成 → 运动路径 → 接触/作用 → 目标与环境响应 → 峰值 → 衰减/残留
~~~

每项只选择需要的阶段，不强制所有效果都经历“蓄力—爆炸”模板。

必须明确效果从哪里产生、传播方向和空间层级、是否被主体遮挡、接触后改变了什么、颜色/亮度/密度怎样衰减，以及最后留下什么状态。

### 6. 按媒介选择效果语言

- **写实/电影 CG**：方向性运动模糊、真实碎屑、接触闪点、空气扰动、材质破坏、真实阴影与光照响应。避免漫画速度线和无来源发光。
- **风格化 3D/2.5D**：关键姿态、受控几何拉伸、姿态残影、图形化冲击帧、分层速度线；保持深度和遮挡关系。
- **纯 2D 动画**：剪影、线条粗细变化、smear、impact drawing、方向性碎片和短暂轮廓破裂；特效作为有起止的动画形状，不是透明滤镜。
- **混合媒介**：3D 负责身体/武器/空间和基础深度；2D 负责图形化冲击、速度线和手绘特效；合成负责遮挡、光溢出、颗粒、曝光和帧率节奏统一。

### 7. 特效选型规则

- **冲击闪光/Impact frame**：只放在决定性接触或明确视觉重音；闪光形状应服从接触方向与画风。
- **Hit-stop/定格**：短暂压住峰值后立刻释放到受击反馈；不应把双方冻结成摆拍。
- **速度线/焦点线**：指向运动方向或视线汇聚点；不能覆盖人物关键轮廓与接触点。
- **Smear/形变残影**：连接起始姿态和结束姿态；不能变成多肢体或身份复制。
- **武器拖尾**：从真实武器运动边缘生成，沿实际轨迹延伸，并在停刀/转向后及时截断或衰减。
- **火花**：仅用于金属摩擦、刃口碰撞、电弧等有来源事件；火花方向继承碰撞速度。
- **冲击波/空气环**：形状、传播方向和尺度对应力源；不默认每拳一个完整圆环。
- **尘土/碎片**：从实际受力面或断裂面发射，继承局部速度，受重力/碰撞影响并沉降。
- **屏幕震动**：由冲击峰值触发，方向与受力一致，迅速衰减；禁止无差别持续抖动。
- **能量/魔法**：先建立来源、形态语法、运动规律、触发条件和代价，再确定颜色与粒子。

### 8. 声音必须和画面同源

重点命中声音分层：接触瞬态、身体响应、环境响应、特效声和尾音。避免每次命中都用同一个低频重击音；不让音效提前于接触或晚于视觉峰值。需要参考音轨时交给音频专项工具处理，本技能不臆造平台音频参数。

### 9. 编译提示词/后期执行单

提示词只保留观众能看到的动作与效果，不输出内部诊断标签。若需后期合成，则输出分层执行单：原始动作层、接触点/冲击帧层、速度线/拖尾层、环境反馈层、合成与色彩统一层、声音层。

不要把后期必须逐帧制作的效果伪装成视频模型必然能一次生成。

### 10. 生成后审片

检查接触点、攻击/受击方向、响应先后、重心和武器惯性、特效来源/路径/遮挡/消散、画面亮度与粒子密度、镜头震动衰减、声音同步，以及跨镜伤势/武器/场景状态。

## 与其他技能协作

先读取本技能动作因果与受力约束；需要完整战斗分镜时调用 storyboard-director-cn。运镜会改变摄影机位置或方向时联读 camera-motion-director-cn。需要大规模场景破坏或材质真实度时联读 scene-realism-director-cn。交付模型专用提示词前，核实目标模型实际支持的素材格式、音频、时间码和控制参数；未核实则只输出通用中文提示词。
