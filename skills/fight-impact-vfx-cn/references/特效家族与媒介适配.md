
# 特效家族与媒介适配

## 效果选择先问“证明什么”

| 观众需要看懂 | 优先机制 | 常见误用 |
|---|---|---|
| 命中方向 | 接触闪点、方向性形状、受击偏转 | 无方向的圆形光环 |
| 极快速度 | 方向性模糊、smear、视差、速度线 | 全屏随机拖影 |
| 武器挥动路径 | 贴合刃口/武器末端的轨迹带 | 脱离武器的独立光带 |
| 金属碰撞 | 接触点火花、金属振动、刃线偏转 | 每拳都喷火花 |
| 重击空气冲击 | 有方向的空气压缩、尘土/衣物波 | 固定大小的透明圆环 |
| 地面/墙体破坏 | 裂纹起点、传播方向、材质碎块 | 无来源碎石雨 |
| 能量攻击 | 能量源、形状、路径、目标响应、余辉 | 随机彩色粒子和 bloom |
| 决定性峰值 | 单帧/短帧冲击图形、短暂 hit-stop | 长时间白屏冻结 |

## 特效生命周期

对重要特效写清来源和拥有者、触发、形成、路径、作用对象、目标/环境/光线响应、衰减与残留。

不是每个特效都需要所有阶段。微小碰撞可简化；英雄级命中需把因果闭合。

## 2D / 2.5D / 3D 选择

| 媒介 | 优先表现 | 控制重点 |
|---|---|---|
| 纯 2D | 手绘冲击图、轮廓破裂、速度线、smear、方向性碎片 | 线条、剪影、节奏、画面构成 |
| 2.5D | 2D 特效形状 + 3D 深度/遮挡 + 分层视差 | 前后景、角色遮挡、摄影机移动 |
| 风格化 3D | 几何拖影、姿态残影、图形化冲击、材质粒子 | 体积、深度、轮廓稳定 |
| 写实 CG | 真实材质破坏、运动模糊、空气扰动、碎屑碰撞 | 物理来源、曝光、阴影、反射 |
| 混合媒介 | 3D 主体/空间，2D 动态图形，合成统一画面 | 帧率、黑位、方向、遮挡和光向统一 |

## 材质反馈速查

- 金属：局部刮擦/弯折/振动；火花只在摩擦、电弧或真实碰撞条件成立时出现。
- 石材：裂纹从受力点向结构薄弱处传播，碎块有重量，粉尘较轻且滞后。
- 木材：沿纹理开裂，出现纤维、碎片和木屑。
- 玻璃：裂纹网、片状破裂和有方向的碎片，注意安全化影视表现。
- 布料/纸张：低质量拖拽、撕裂、翻卷和较长飘落。
- 水：波前、飞溅、回落和表面波纹，方向继承撞击方向。
- 能量/魔法：先确定能力来源与形态语法，再选择颜色；不同角色/阵营不应只靠换颜色区分。

## 画面层级

- 主层：接触/轨迹/冲击形状，只能有一个主要视觉焦点。
- 次层：碎屑、空气、衣物、局部光照，用于证明力的传播。
- 氛围层：烟雾、细粒子、余辉，必须低于主体对比度。

画面过乱时先删氛围层，再减次层，最后才动主层。
