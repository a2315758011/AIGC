
# 特效审片与失败诊断

| 缺陷码 | 可见问题 | 优先根因 | 修正方向 |
|---|---|---|---|
| FV01 | 隔空命中却出现巨大爆炸 | 接触关系缺失 | 先修距离、接触点和受力路径 |
| FV02 | 受击者提前后仰 | 时间因果颠倒 | 将响应放到接触之后 |
| FV03 | 命中无重量 | 缺少位移/失衡/支撑变化 | 补受力者和脚步结果，不先加粒子 |
| FV04 | 重武器像泡沫 | 缺少惯性和制动 | 补武器末端滞后、拖尾、反向平衡 |
| FV05 | 火花/闪光没有来源 | 特效所有权不明 | 锁定接触点、碰撞对象和方向 |
| FV06 | 特效遮住动作 | 主次层级错误 | 降低亮度/密度、缩小覆盖区、移开脸和接触点 |
| FV07 | 冲击波像贴纸 | 缺少空间和遮挡 | 让波前与深度、方向、场景物体交互 |
| FV08 | 碎片漂浮或穿模 | 发射速度/重力/碰撞缺失 | 从破裂面生成并继承局部速度 |
| FV09 | 拖尾不跟武器 | 轨迹与源运动脱节 | 锁定发射点、速度、路径和结束截断 |
| FV10 | 全程抖屏 | 镜头响应没有峰值控制 | 只在关键冲击后触发并快速衰减 |
| FV11 | 所有打击一个节奏 | 缺少力量等级差异 | 分配轻/中/重命中预算 |
| FV12 | 画面过曝或全屏发白 | bloom/闪光占主导 | 恢复轮廓、黑位和材质对比 |
| FV13 | 音效提前/滞后 | 事件时间轴未绑定 | 以实际接触帧为同步锚点 |
| FV14 | 跨镜伤势/破坏重置 | 连续性状态未继承 | 建立角色、武器、场景损伤状态表 |

## 验收抽帧

至少查看接触前、接触帧、接触后、拖尾段和下一镜。分别检查攻击方向、接触点、受击响应、环境反馈、惯性衰减与状态继承。

高风险镜头逐帧检查；普通镜头至少检查首、中、尾三个位置。记录素材、帧率、抽帧范围和实际缺陷，不能只凭“看起来很燃”验收。
