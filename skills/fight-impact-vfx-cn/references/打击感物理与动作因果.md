
# 打击感物理与动作因果

## 核心链

打击感不是粒子强度，而是观众看见力如何产生、传递和停止：

~~~text
支撑/预载 → 重心移动 → 肢体或武器加速 → 接触/格挡/擦身 → 受力传递 → 受击者响应 → 拖尾/制动 → 新状态
~~~

如果接触前受击者已后仰，或接触后身体没有改变状态，画面会显得假。

## 身体与武器检查

- 支撑：哪只脚承重？是否滑移、转轴或失去支撑？
- 重心：胸腔、骨盆和头部是否沿合理路径移动？
- 发力：动作是否从支撑与躯干传到肢体/武器？
- 距离：攻击者是否真正进入有效距离？
- 接触：拳、刃、柄、盾、护甲或地面在哪个位置发生作用？
- 受力：受力方向是否与攻击路径一致？
- 代价：谁需要后退、转体、跪地、失衡、松手或调整步伐？
- 收势：武器惯性、身体刹车和下一动作如何衔接？

## 武器质量差异

| 系统 | 视觉时间感 | 关键反馈 |
|---|---|---|
| 徒手/短兵 | 快速预备与短峰值 | 肩胯传力、接触压缩、短促回收 |
| 单手中型兵器 | 清楚起势、快速刃线 | 握持/护手受力、刃线偏转、脚步修正 |
| 头重/长柄/巨型武器 | 蓄势与拖尾明显 | 武器末端滞后、身体反向平衡、长制动 |
| 柔性/链状武器 | 动作沿长度传播 | 手柄先动、末端延迟、张力回弹 |
| 超常力量 | 可压缩准备时间 | 地面、空气、衣物、目标或结构提供力量证据 |

这些是视觉导演启发式，不是现实人体动力学的定量仿真。

## 接触事件的六种结果

- 命中：接触点明确，受力者发生相应变化。
- 格挡：武器/肢体相碰，攻击线被改变，双方平衡与距离改变。
- 擦身：攻击未命中，空气/衣物/头发/地面反馈方向正确。
- 近失误：攻击路径贴近目标，目标主动避开，双方空间关系改变。
- 绑定/压制：双方短暂共享约束，必须有支撑、力线和释放结果。
- 中断：动作被环境、第三方或自身失衡打断，下一动作由中断状态产生。

## 反假打审查

以下任一问题都应先修动作：
- 双方隔空挥动却出现巨大爆炸；
- 受击者提前反应；
- 接触位置与身体形变不一致；
- 武器穿过身体或在接触后突然变形；
- 重武器没有惯性、拖尾或恢复；
- 双方反复回到相同站姿，交锋没有状态积累；
- 特效遮住接触点，让观众无法判断发生了什么。

## 受击反馈层次

由内向外逐级建立，不要求每层每次都出现：
1. 接触局部：压缩、偏转、护甲/布料局部形变。
2. 身体链：头肩、胸腔、骨盆、脚步按力线响应。
3. 表演：表情、视线、吐气、短暂动作中断。
4. 装备：武器震颤、护手偏移、衣物抽动。
5. 环境：灰尘、水、树叶、碎屑、地面或墙面反馈。
6. 画面：短暂冲击帧、局部曝光变化、受控镜头冲击。

决定性重击要有明显的受力结果；普通擦碰保持克制。
