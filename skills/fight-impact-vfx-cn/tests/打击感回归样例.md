
# 打击感回归样例

以下是技能规则的人工验收样例，不是已运行的视频模型基准。

| 样例 | 输入问题 | 应判定 | 预期修正 |
|---|---|---|---|
| T01 隔空重击 | 两人相距明显，拳头未接触，画面却爆出巨大冲击波 | 不通过 | 先重排距离和接触关系；没有接触则改成明确近失误 |
| T02 受击提前 | 防守者在拳头抵达前已飞出 | 不通过 | 让位移/表情响应发生在接触后 |
| T03 重剑无惯性 | 巨剑像轻棍一样瞬间停住 | 不通过 | 增加预备、末端滞后、拖尾和制动 |
| T04 每击都爆炸 | 轻格挡、擦碰和重击都用同一白闪/冲击环 | 不通过 | 按 L1-L4 分配反馈预算 |
| T05 火花无归属 | 火花从画面中心随机喷出，与武器接触点不一致 | 不通过 | 绑定接触点、碰撞方向和材质 |
| T06 特效盖动作 | 全屏光效遮住人物脸、手和命中位置 | 不通过 | 降低亮度/面积，恢复主轮廓和接触证明 |
| T07 声画错位 | 音效在命中前出现或远晚于画面 | 不通过 | 以实际接触帧为同步锚点 |
| T08 受击无结果 | 接触发生但受击者站姿、平衡、武器线和环境都不变 | 不通过 | 选择至少一个可见状态变化 |
| T09 方向一致 | 斜向右上的攻击，尘土/碎片却向左下喷射 | 不通过 | 统一攻击、受击和环境反馈方向 |
| T10 纯 2D 混入写实粒子 | 手绘角色上叠加大量写实火花，风格冲突 | 不通过 | 统一媒介和线条/帧率/材质语言 |
| T11 冲击峰值克制 | 普通擦碰只有局部振动，决定性重击有明确峰值和后果 | 通过 | 保持强弱对比 |
| T12 状态连续 | 下一镜保留武器损伤、受击姿态和地面裂纹 | 通过 | 继承状态，不重置 |
