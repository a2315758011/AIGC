# DirectorDesk 三维白模预演适配规范 V1

## 目的

复用用户已安装的 DirectorDesk 三维导演台作为高风险场景的白模预演工具，不另建重复的 3D 编辑器、模型库或碰撞服务。本规范将 AIGC 场景数据库与 SCG 映射到 DirectorDesk 的已有能力，并明确哪些能力不能被夸大。

## 权威数据分工

- 场景数据库：固定建筑、家具、稳定 ID、坐标单位、占地与碰撞体积。
- SCG：逐镜人物/道具/摄影机状态、关系、事件和路径。
- DirectorDesk：预演执行与可视化检查器；它的临时场景副本不得反向覆盖权威场景事实，除非经人工审核并更新场景数据库/SCG。
- 生成视频：模型实际输出，必须与白模逐镜对照；DirectorDesk 白模通过不代表视频模型服从。

## 坐标适配（必须显式转换）

AIGC 场景数据库当前约定 X 左右、Y 前后、Z 高度；DirectorDesk 约定世界坐标以米为单位、+Y 向上，人物局部前方为 +Z。

不得直接复制坐标。导出前建立场景级轴映射与原点变换：
- X_D = X_AIGC
- Y_D = Z_AIGC
- Z_D = s × Y_AIGC，其中 s 由已批准场景的“前/后”方向确定，可为 +1 或 -1
- 若两个系统原点不同，另加经批准的 originOffset。
- 旋转、相机 look-at、路径 heading、门扇开合方向必须使用同一变换；不能只转换人物位置。
- 归一化坐标不得直接当米制。没有实测尺寸时可制作比例白模，但必须标记为相对比例，不得声称人体工学/真实净宽已验证。

每个 .director 预演包必须保存 transform manifest：source_scene_id、scene_database_revision、SCG_revision、source_units、axis_mapping、origin_offset、转换时间和导出对象 ID 对照表。

## 能力映射

### 固定场景与家具

- 使用 DirectorDesk 已有家具/建筑资产或参数化白模；优先复用已安装资产，不复制新模型库。
- 静态家具/墙体作为 static 碰撞障碍；房间结构本身也参与碰撞。
- 对复杂家具使用多个简单盒体组成复合障碍；不要用一个过大的盒子堵死可通行区域。
- 使用空间查询返回的 contactAnchors 作为桌面、座面、床面、层板等接触参考；修改模型结构后重新查询，不沿用过期锚点。
- 对未知尺寸/未知门扇扫掠范围保持 UNRESOLVED，不能由生成图反推精确几何。

### 人物和动作

- 使用稳定角色 ID 的白模 actor；身体动作 clips 与根节点 path 分开设置。
- 角色根路径用于整体位移/旋转；walk/run/sit/standup 等动作片段驱动动作轨道。不能把静止人形沿路径平移说成自然行走。
- DirectorDesk 的普通人形碰撞体是简化代理，不等同于按骨骼姿态变化的精确人体胶囊/网格。坐下、弯腰、摔倒、打斗、手腕抓握等动作必须额外抽查姿态、遮挡和接触。
- 抓握、拔针、插接、戴戒指等关键接触没有真实 IK/骨骼约束证据时，必须标记近似/阻塞，不能以两个物体靠近判定接触成功。

### 路径与碰撞

- DirectorDesk 物理支持 gravity、static/dynamic/kinematic、碰撞、惯性及简化 box/sphere/auto 形状；默认关闭，按需启用。
- 物理为近似模拟，高速细物体可能穿透；不能替代精确人体仿真。
- 内置自动避障是同高度地面、静态障碍的二维规划；不支持楼梯、攀爬或完整动态人群寻路。多人相交路径仍需在同一时间轴上人工/结构化检查。
- AIGC 的三维 AABB 校验器用于提交前的保守静态路径检查；DirectorDesk 用于实际空间预览、物理近似和视觉检查。两者职责互补，不互相替代。

### 摄影机

- 摄影机位置 path 与 camera.targetPath（视线/注视点路径）是独立通道，必须分别定义和验收。
- 使用 DirectorDesk 实际预览焦距、景别、遮挡、轴线和完整相机轨迹；camera target path 不是持续绑定角色，除非工具明确设置目标跟随。
- AIGC 的相机碰撞球代理只检查已知静态障碍，不检查视锥遮挡、FOV、画面主体构图；这些必须在实际机位预览中检查。

## 最小预演流程

1. 读取场景数据库与 SCG，检查固定事实、动态状态、未知项和稳定 ID。
2. 建立坐标变换 manifest；核对单位、轴向、原点、门窗朝向。
3. 生成独立 .director 白模副本，不修改用户现有工程。
4. 导入/摆放固定场景、家具、演员代理、道具和摄影机。
5. 对高风险人物动作设置 path + clips；关键接触点使用 contactAnchors 和必要的物理近似。
6. 运行 AIGC 三维路径校验器；再在 DirectorDesk 实际播放，检查俯视、正视、侧视和镜头视角。
7. 逐镜抽查起始、中间、接触、转向、切点和结束状态；保存工程、参考帧/视频、QA 缺陷和坐标转换清单。
8. 将通过审核的固定场景事实/动态状态回写到场景数据库或 SCG；不把导演台临时对象状态自动回写为权威数据。
9. 将目标视频模型输出与预演对照，独立记录其遵循度。
