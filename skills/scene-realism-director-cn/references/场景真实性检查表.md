# 场景真实性检查表

用途：AI 生成室内/室外场景图、漫剧背景、建筑空间图的独立验收。按顺序检查，不以“整体很漂亮”抵消硬错误。

## A. 场景用途与常识
- [ ] 空间用途与物件组合一致（教室/办公室/厨房/医院/街道等）。
- [ ] 固定设施符合真实建筑逻辑；出入口、窗、门、楼梯、走廊连接合理。
- [ ] 家具摆放符合行为需求；没有无理由堵路、遮门或无法使用的布局。
- [ ] 场景中不出现与地域、年代、天气、用途冲突的设施或装饰。

## B. 空间与尺度
- [ ] 房间/建筑边界闭合，墙地顶关系成立。
- [ ] 主要物体有可解释的世界位置、朝向、尺寸和支撑关系。
- [ ] 物体之间没有无意义穿插、重叠或悬浮。
- [ ] 通行宽度、门扇开启、抽屉拉出、椅子后退和工作空间足够。
- [ ] 前景/中景/后景层级清楚，遮挡顺序符合相机位置。

## C. 透视与摄影
- [ ] 地平线/相机高度与观察角度相容。
- [ ] 同组平行边缘的消失方向相容；垂直线是否倾斜有合理镜头解释。
- [ ] 同一平面、同类物体的透视缩放一致。
- [ ] 镜头视角没有无故夸大边缘、拉伸家具或压扁空间。
- [ ] 画面边缘裁切有意图，不切掉关键结构或制造错误连接。

## D. 光照与阴影
- [ ] 能指出主要光源的位置/方向（窗、太阳、灯具、屏幕等）。
- [ ] 同一光源形成的投影方向一致；软硬程度与光源大小/距离相符。
- [ ] 接触处有适当接触阴影/遮蔽，不出现明显漂浮。
- [ ] 受光面、背光面、反射光和环境亮度关系合理。
- [ ] 玻璃、镜面、金属反射内容与周围环境和视角相容。

## E. 材质与表面
- [ ] 木、石、金属、玻璃、塑料、织物、混凝土具有不同的反射/粗糙特征。
- [ ] 纹理尺度与物体尺寸匹配，不出现过大木纹、巨型布纹或重复贴图。
- [ ] 高光不过度统一；非金属材质不被处理成镜面。
- [ ] 有使用痕迹时，位置符合接触、磨损、潮湿、日晒和清洁逻辑。
- [ ] 细节丰富度与景深/分辨率一致，不出现局部过锐或涂抹。

## F. AI 痕迹
- [ ] 无融化边缘、结构粘连、重复窗格/砖纹/书本、无意义文字。
- [ ] 细节不是随机堆砌；物件有明确功能和结构。
- [ ] 不同区域的锐度、噪声、纹理频率没有突兀断层。
- [ ] 无过度 HDR、过度锐化、过度降噪和塑料皮肤/塑料墙面感。

## G. 验收方式
每个场景分别记录：场景 ID、模型/版本、提示词版本、参考图、种子（若可用）、分辨率、控制图/权重、后处理、检查者、问题位置、严重度、修复动作、复测结果。
- P0：结构、拓扑、透视或物理关系错误；直接退回。
- P1：明显材质/光影/比例/AI 痕迹；修复后复测。
- P2：局部细节/美术润色；不阻断结构验收。
- 不确定：写“无法从单张图判断”，不得假定通过。
