# 第三方评测器部署门槛 V1

## SpatialGenEval
官方仓库：https://github.com/AMAP-ML/SpatialGenEval
官方 README 列出 Python 3.10、PyTorch、Transformers、Diffusers、ModelScope、vLLM；评审路线使用 Qwen2.5-VL-72B-Instruct 或 GPT-4o。该路线不应在硬件未核验前安装。

## Qwen-Image-Bench
官方仓库：https://github.com/QwenLM/Qwen-Image-Bench
官方 README 说明 Q-Judger 基于 Qwen3.6-27B，需 PyTorch 与 ms-swift。其五大维度、56 个细分标准可作评分参考，但 27B 评审器不设为必装依赖。

## 本项目采用决定
1. 优先使用原创中文配对基准与人工盲评。
2. 不复制大型环境，不下载模型权重，不占用 GPU。
3. 确认硬件、许可、服务费用后才评估自动评审器。
4. 自动评分不能代替对门窗连接、过道通行、物体支撑等空间事实的复核。
5. 目标模型 A/B 生图仍未执行，不能宣称效果已改善。
