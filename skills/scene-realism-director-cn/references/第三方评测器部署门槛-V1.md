# 第三方评测器部署门槛 V1

## SpatialGenEval
官方仓库：https://github.com/AMAP-ML/SpatialGenEval
官方 README 列出 Python 3.10、PyTorch、Transformers、Diffusers、ModelScope、vLLM；评审路线使用 Qwen2.5-VL-72B-Instruct 或 GPT-4o。该路线不应在硬件未核验前安装。

## Qwen-Image-Bench
官方仓库：https://github.com/QwenLM/Qwen-Image-Bench
官方 README 说明 Q-Judger 基于 Qwen3.6-27B，需 PyTorch 与 ms-swift。其五大维度、56 个细分标准可作评分参考，但 27B 评审器不设为必装依赖。

## 本项目采用决定
1. 优先使用原创中文配对基准与人工盲评。
2. 不复制大型环境，不下载模型权重，不占用 GPU。
3. 确认硬件、许可、服务费用后才评估自动评审器。
4. 自动评分不能代替对门窗连接、过道通行、物体支撑等空间事实的复核。
5. 目标模型 A/B 生图仍未执行，不能宣称效果已改善。


## Shedding Light（2026）
官方仓库：https://github.com/JustineGiroux/SheddingLightBenchmark  
许可证：MIT。README 提供约 220 MB 的 GT/遮罩/预计算结果；完整生成图子集约 122 GB。方法依赖真实室内光探针，计算光照方向、Delta E 和辐射分布差异。  
决定：只借鉴光照评估设计；不下载 122 GB 子集，不默认安装 GPU 依赖。注意 README 的 1,006 benchmark 场景与底层 Multilum 1,016 场景是不同统计口径。

## CFM / Too Vivid to Be Real?（CVPR 2026）
官方仓库：https://github.com/ZhengyaoFang/CFM  
许可证：Apache-2.0。CFD 约 1.33M 张图；CFM-7B 评估颜色忠实度；CFR 是需要目标扩散流程支持相应参数的免训练修正方法。作者 README 推荐 Python 3.11、PyTorch 2.5.1。  
决定：不在工作站默认安装 7B 模型；先用人工检查颜色、白平衡、曝光和饱和度。禁止把 CFR 简化成全图降饱和滤镜。

## PICABench / PICAEval（ICLR 2026）
官方仓库：https://github.com/Andrew0613/PICABench  
README 采用区域级问答，覆盖光学、力学和状态变化。GPT 评测会上传图像并产生 API 费用；Qwen 路线需要 Qwen2.5-VL-72B/vLLM 多 GPU。仓库未发现可确认的 LICENSE 元数据。  
决定：不复制代码/数据，不启用付费 API，不部署 72B。只借鉴“编辑区域 + 是/否物理问题 + 非编辑区域一致性”的评测结构。该基准针对图像编辑，不等同于纯文生图评分。

## ImagenWorld（ICLR 2026）
官方论文页：https://proceedings.iclr.cc/paper_files/paper/2026/hash/458fa8ee331566383d8e74bdb647f829-Abstract-Conference.html  
3.6K 条条件集、20K 细粒度人工标注，支持局部对象/区域错误归因。  
决定：借鉴“指出哪个物体/区域/违反哪条规则”的报告格式；代码和数据许可未确认，不复制。

## 对象级真实感（CVPR 2025）
论文：https://openaccess.thecvf.com/content/CVPR2025/html/Liang_Be_More_Specific_Evaluating_Object-centric_Realism_in_Synthetic_Images_CVPR_2025_paper.html  
将对象真实感拆成形状与纹理。  
决定：关键物体近景分开检查轮廓/结构与材质纹理，不将整体场景分数当作对象真实感证明。
