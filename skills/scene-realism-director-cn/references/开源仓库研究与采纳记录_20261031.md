# 场景真实性控制开源仓库与方法研究记录

日期：2026-10-31
目标仓库：a2315758011/AIGC
研究目标：搜集可控制场景结构、空间布局、透视、深度、参考图一致性和建筑视觉真实性的公开仓库/技能；只采纳可解释、可复现且与现有体系不重复的方法。

## 1. 核心结论

场景“假”不是单一问题。至少要区分：
- 世界结构错误：墙体、门窗、空间边界不成立；
- 功能布局错误：家具/设施不符合房间用途，通道和操作空间不合理；
- 几何错误：透视、比例、深度、接触和遮挡不一致；
- 外观错误：材质、光照、阴影、纹理尺度不可信；
- 来源漂移：参考图中正确结构被模型擅自修改；
- 视角/全景错误：俯视类型混淆、拼缝断裂、极点畸变、画外结构被编造。

不能只靠更长提示词解决。最可靠的工作流是：场景事实简报 → 空间骨架/布局 → 结构控制图 → 生成/编辑 → 独立视觉质检 → 单变量修复。

## 2. 已审查来源

### A. ControlNet 官方研究仓库
- 仓库：https://github.com/lllyasviel/ControlNet
- 本轮 main HEAD：ed85cd1e25a5ed592f7d8178495b4483de0331bf
- 研究：ControlNet 将空间条件（如边缘、深度、姿态、分割等）引入扩散生成；比纯文本更适合约束已知的构图和结构。
- 采纳：当建筑轮廓、门窗位置、家具边缘或空间布局必须保持时，优先考虑边缘/深度/分割条件，而非只追加文字。
- 限制：ControlNet 只能约束输入控制图表达的内容；控制图本身错了，生成结果会继承错误。模型兼容性、权重和参数必须按具体工作流验证。
- 许可证：仓库页面显示 Apache-2.0；本次只引用方法，不复制源代码或权重。

### B. ComfyUI ControlNet Auxiliary Preprocessors
- 仓库：https://github.com/Fannovel16/comfyui_controlnet_aux
- 本轮 main HEAD：a587a4c1594524c1d2de5cd1a86cd868ff448e1c
- 关键能力：Canny、HED/SoftEdge、Lineart、MLSD、MiDaS、LeReS、Zoe、Depth Anything/Depth Anything V2、Metric3D、Normal、OneFormer语义分割等预处理器。
- 采纳：把原图转换为边缘、深度、法线、语义分割控制图；分别用于保护墙线/门窗轮廓、空间前后关系、表面方向和区域类别。
- 限制：深度估计是单目估计，不等于精确测量；语义分割可能把相似物体分错；法线/边缘图需要人工检查。依赖项较多，Windows GPU/ONNX/PyTorch版本可能引发安装和运行问题，先在隔离环境验证。
- 证据：ComfyUI 官方 workflow_templates 的节点知识页列出该节点包、下载量和关键节点；上游仓库更新记录显示包含 Depth Anything V2、Metric3D、DSINE 等，并记录过导入、性能和兼容问题。
- 许可证：上游仓库含许可证文件；具体预处理器依赖和模型权重可能有各自许可，商用前必须逐项核对。只引用能力，不复制实现/权重。

### C. Depth Anything
- 仓库：https://github.com/LiheYoung/Depth-Anything
- 本轮 main HEAD：1d03336771fe09c5398ffdd211441e33941a97dc
- 研究：单目深度估计可为单张场景图提供相对前后层级提示。
- 采纳：将深度图用于发现近远关系异常、构建深度条件或评估大幅相机运动风险。
- 限制：单张图的深度结果不自动恢复被遮挡几何；相对深度不应冒充绝对尺寸。具体模型版本与权重许可须核对。
- 论文/项目：CVPR 2024；https://arxiv.org/abs/2401.10891

### D. ComfyUI 官方工作流模板
- 仓库：https://github.com/Comfy-Org/workflow_templates
- 本轮 main HEAD：c067929d7e9cc0f3fd15be348fa1a1d85da15946
- 研究：官方仓库维护可复用工作流模板、子图蓝图和节点知识说明；其中 ControlNet Aux 说明列出深度、边缘、线稿和姿态预处理能力。
- 采纳：实际落地时优先寻找当前版本官方模板/节点蓝图，避免从零拼接和使用失效节点。
- 限制：仓库包含多种媒体工作流，不代表每个模板都适合场景重建；必须核对具体模板的模型、节点和版本。
- 许可证：本轮未完整核验所有模板和依赖资产的许可证；只作方法和导航参考，不复制模板文件。

### E. Architectural Visualization Prompt Library
- 仓库：https://github.com/jac2020-2020/architectural-visualization-prompt-library
- 本轮 main HEAD：ac558e559d80b9d2d4c0cd66ff3a5eb1d6de9206
- 版本/声明：README 标记 0.1.0，披露 10 个案例基准；声明跨模型覆盖尚不完整。
- 研究：CORE 结构把 Context/Constraints、Objective、Rendering、Evaluation 分开；参考图编辑明确“保持什么/允许改什么”；将空间布局、材料、光照、相机和评估分开。
- 采纳：采用“来源事实—保留项—允许变化—渲染目标—评估条件”的提示词组织方式；记录首轮失败和单变量修复。
- 限制：该库偏建筑/室内视觉概念，不是可执行几何引擎；其 10 案例不构成跨模型普遍有效的证明。README 声明 MIT；本仓库仅提炼方法，不复制其模板正文。

### F. ComfyUI IPAdapter Plus
- 仓库：https://github.com/cubiq/ComfyUI_IPAdapter_plus
- 本轮 main HEAD：a0f451a5113cf9becb0847b92884cb10cbdec0ef
- 研究：参考图条件可传递主体/风格/部分视觉特征；仓库包含多种示例工作流。
- 采纳：仅把参考图适配器视为外观/风格/参考条件，不把它等同于精确几何约束。
- 限制：维护者在 README 明确 2025-04-14 起进入 maintenance-only；不作为新项目默认依赖，兼容实现和模型许可需另行核验。

## 3. 交叉验证与关键边界

- OpenAI 图像生成指南强调场景/主体/细节/约束的清晰结构，编辑时重复声明几何、布局等不变量，并建议小步迭代。它是提示词指导，不是几何保证：https://developers.openai.com/cookbook/examples/multimodal/image-gen-1.5-prompting_guide
- ComfyUI 官方节点知识页说明 ControlNet Aux 产生边缘、深度、姿态、线稿等控制图：https://github.com/Comfy-Org/workflow_templates/blob/main/site/knowledge/custom-nodes/comfyui-controlnet-aux.md
- Architectural Visualization Prompt Library 明确说明文字约束不能保证几何尺寸或规范合规，参考图每次生成后必须核对：https://github.com/jac2020-2020/architectural-visualization-prompt-library

## 4. 采纳决策

| 方法/来源 | 决策 | 用途 |
|---|---|---|
| ControlNet | 采纳 | 已知结构的条件控制 |
| ControlNet Aux | 采纳 | 生成边缘/深度/法线/分割提示图 |
| Depth Anything | 采纳 | 单图相对深度辅助，不作尺寸真值 |
| ComfyUI 官方工作流模板 | 采纳 | 查找可复用、版本匹配的工作流 |
| 建筑可视化 CORE 框架 | 采纳 | 组织事实、保留项、变化项和评估标准 |
| IPAdapter Plus | 限定参考 | 仅参考旧工作流与条件控制思路；维护模式，不作新项目首选 |
| 纯提示词堆叠“8K/超写实” | 不采纳 | 不能修复空间矛盾和几何错误 |
| 未核验许可证的代码/权重复制 | 不采纳 | 版权、商用和依赖风险 |

## 5. 对现有 AIGC 仓库的增量

现有仓库已有场景空间层级、对象恒常性、人物站位与场景调度、摄影机运动规则；这些解决跨镜世界状态和人物/摄影机连续性。本次新建的 scene-realism-director-cn 补齐静态场景图的建筑拓扑、功能布局、透视尺度、接触遮挡、光材真实性、参考图保真与全景完整性。两者协作但不重复。

## 7. 下一轮推荐实验

固定同一教室/办公室场景简报、模型版本、分辨率和种子（若接口支持），比较：
A. 纯文本基线；
B. 参考图 + 保留/变化约束；
C. 参考图 + Canny/Lineart；
D. 参考图 + Depth；
E. 结构白模/平面图 + ControlNet。
分别检查墙体/门窗、家具数量位置、通道、透视、接触阴影、材质和边缘漂移。每轮只改变一个主要变量，保留全部失败结果。
