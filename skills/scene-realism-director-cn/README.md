# 场景真实性导演与独立质检 Skill V1.0.0

本技能专门处理 AIGC 场景图“看起来假、不符合常识、空间关系不成立、建筑结构错误、透视比例异常、家具悬浮/穿插、光影材质塑料感”等问题。

## 包含内容
- SKILL.md：触发条件、强制工作流、技能协作边界。
- references/场景真实性控制规则-V1.md：权威方法规则，覆盖空间拓扑、功能布局、相机透视、物理接触、光照材质、全景和迭代。
- references/开源仓库研究与采纳记录_20261031.md：第三方开源来源、版本/提交、采纳与排除理由、许可证边界。
- references/场景图真实性质检与回归样例-V1.json：可复用的人工回归案例和验收标准。
- SOURCE_LOCK.json：源文件 SHA 与版本锁定。

## 使用方式
把整个 scene-realism-director-cn 文件夹导入支持本地 Skill 的 AI 客户端。只导入 SKILL.md 不完整；需要一并提供 references 和 SOURCE_LOCK。

## 适用场景
教室、办公室、住宅、医院、商铺、街道、建筑外观、自然环境、正交俯视、轴测、参考图修复、360/720全景和影视场景母版。

## 验收边界
本技能包含方法规则和人工回归案例，尚未接入自动图像评分模型，也没有在 ComfyUI 上实测完整工作流。不得把静态文档检查说成生成效果验证。
