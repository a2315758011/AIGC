# 漫画读者测试与页面质检清单 V1

适用：欧美英语彩色漫画；日漫/其他阅读方向必须显式设置 reading_direction，不能套用默认。

## A. 读者测试（脚本关闭）
让未读过剧本的人按正式阅读顺序浏览页面，逐页回答：
1. 我现在在哪里？时间/地点是否清楚？
2. 当前画面有哪些人物？是否能识别首次登场者？
3. 谁在做什么？动作因果是否能从画面/文字理解？
4. 对白是谁说的？气泡尾巴是否指向正确角色？
5. 这一页/屏为什么要继续读？结尾是否有悬念或情绪落点？
6. 是否需要回看上一页才能理解当前页？若需要，是否为有意设计？

任何一项关键剧情理解只能靠制作人员解释，标记 P1；不能靠读者自行猜测补全。

## B. 每格审核
- [ ] 与分格脚本的角色、动作、景别、角度、背景一致
- [ ] 角色脸型、发型、年龄观感、服装版本、饰品一致
- [ ] 同一角色在同一格只出现预期次数；背景群众不会复制主角
- [ ] 手、脸、肢体、道具接触和动作因果成立
- [ ] 场景拓扑、门窗/地标、光线方向、时间与前后格连续
- [ ] 主体没有被格框意外切头/切手；关键动作未被气泡遮挡
- [ ] 画面留白与最终气泡位置相容
- [ ] 画面内没有模型伪文字、错拼品牌、意外水印或无关签名

## C. 页面与阅读顺序
- [ ] 按目标地区阅读方向检查完整页面；欧美英语项目默认 LTR，但需显式确认
- [ ] 先看画面再读文字，视觉焦点和对白顺序自然
- [ ] 气泡不遮挡脸、手、关键道具、动作接触点
- [ ] 气泡尾巴指向正确说话者；多人对话不交叉误导
- [ ] 旁白/场景字幕不与气泡争夺同一位置
- [ ] 英文文本不溢出；首字母和末字母完整；无遮挡、叠字、孤行
- [ ] 页面最多使用有限的气泡强调样式；强调效果服务剧情而非装饰堆叠
- [ ] 页面格框和间距具有设计意图；倾斜格只在画面透视/动作确实需要时使用

## D. 英文对白专项
- [ ] 保留剧本原意、人物声线和信息量；不得为适配气泡擅自改写剧情事实
- [ ] 逐条核对说话者、标点、大小写、拼写和语法
- [ ] 朗读对白检查自然度和角色语气
- [ ] 以手机实际显示尺寸检查字号、行长、断句和可读性
- [ ] 旁白、对白、拟声词分层；字体具备商业使用许可
- [ ] SFX 的词义、形态、大小、旋转和位置符合动作/文化/时代语境

## E. 连续性对照
将同一角色所有已批准画格、封面、宣传图并排：
- 身份、脸型、眼睛、发型和关键标志
- 服装版本、颜色、材质、饰品
- 伤势、诅咒、污渍、持有道具和状态变化
- 身高关系、年龄观感、身体比例
场景并排检查：
- 门窗/家具/建筑锚点
- 摄影机方位、时间、光源方向和色温
- 关键道具位置和状态
不一致时只返工受影响的格；不允许用重新生成整页覆盖批准画格。

## F. 出版预检
- [ ] 网漫长条与分页版是独立布局，不是简单切片
- [ ] 文件尺寸、分辨率、DPI 和色彩空间符合目标平台/印刷厂当前官方要求
- [ ] 出血、裁切线、安全区、跨页、页码、封面和章节顺序正确
- [ ] 字体嵌入或已正确转曲；检查缺字与替换字体
- [ ] PDF/CBZ/EPUB 可重新打开，页面数和文件大小正确
- [ ] 文字层、画格源图、批准图和编辑源文件可追溯
- [ ] 版权、字体、模型、LoRA、素材和 AI 披露已核验

## G. 缺陷分级
- P0：剧情/身份/对白严重错误、版权风险、文件不可打开。禁止发布。
- P1：角色漂移、动作因果/场景连续性错误、气泡归属/遮脸、文字溢出、读者无法理解。禁止发布。
- P2：局部纹理、线条、间距等可见瑕疵，不改变叙事。
- P3：纯装饰性优化。

出版候选必须 P0=0、P1=0；P2/P3 是否接受需由制作负责人记录。

## H. 必须保留的证据
每轮至少保存：页面渲染图、逐格脚本、人物/场景参考版本、对白源数据、质检记录、缺陷修复前后图、最终导出文件哈希。
静态脚本检查不能替代视觉读者测试；作者自报测试不能替代本项目实测。
