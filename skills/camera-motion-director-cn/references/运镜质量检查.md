# 运镜质量检查

## 一、审片范围

必须说明实际检查了什么：
- 全片正常速度播放；
- 首/中/尾关键帧；
- 运动开始、最大位移、减速停止区间；
- 高风险位置逐帧或抽帧；
- 是否检查了连续镜头的前后衔接。

只读提示词、只看生成任务状态或只看一张截图，不算视频运镜验收。

## 二、检查维度

| 维度 | 通过标准 | 典型失败 |
|---|---|---|
| 运镜执行 | 实际发生了指定运动，方向和主次正确 | 没有动、做成别的运动、方向反了 |
| 轨迹连续 | 速度和路径连续，起停自然 | 突跳、抖动、忽快忽慢、路径折返 |
| 透视/视差 | 前中后景变化符合机位运动 | 背景拉伸、墙体弯曲、透视跳变 |
| 主体稳定 | 人物身份、身体结构、商品形状保持 | 换脸、肢体增生、产品变形 |
| 空间连续 | 人物站位、距离、轴线、视线和场景布局保持 | 人物漂移、左右互换、穿墙、跨轴 |
| 动作独立性 | 主体动作与摄影机运动各自符合指令 | 人物被迫移动来“配合镜头” |
| 焦点 | 焦点落在目标上，变化有理由 | 抽动、跑焦、无目标移焦 |
| 画面边界 | 运动不暴露不合理的空洞或生成边缘 | 黑边、拉伸、缺失结构、错误补画 |
| 收尾 | 运动平滑减速，最终构图稳定可读 | 突然停止、最后几帧崩坏、持续漂移 |
| 风格连续 | 光线、色彩、材质与前镜一致 | 闪烁、纹理爬动、曝光脉冲 |

## 三、缺陷分级

- **P0 阻断**：运动导致核心人物/商品身份错误、场景结构不成立、人物瞬移/换位、镜头路径物理不可能、关键剧情信息不可读。
- **P1 必修**：运镜类型或方向错误、明显透视漂移、轴线/视线破坏、主体被裁切、重要道具状态不连续、收尾失稳。
- **P2 优化**：轻微速度不匀、运动幅度略弱、构图停留时间不足、非关键背景纹理闪烁。

## 四、根因修复顺序

1. 源图本身不支持目标路径：先修源图或补充多视角/分层/3D。
2. 运镜类型错误：先区分旋转、位移、变焦、移焦。
3. 轨迹过大：减小角度/距离，不要叠加更多禁止词。
4. 摄影机与人物动作冲突：降低其中一方复杂度，保留人物原有世界坐标。
5. 轴线或站位错误：回到分镜空间状态，修正最早冲突镜头。
6. 提示词含混：明确起点、方向、幅度、相对位置、终点。
7. 模型不支持：改用真实可用的控制接口或更适合的制作路径。

每次迭代只改一个主要变量，保留前版结果，记录变化和差异。连续两轮没有改善，重新判断根因；不要无限重复生成。

## 六、放行标准

P0=0、P1=0 才可标记“运镜审片通过”。P2 可以保留但必须说明。没有实际视频时只能标记“方案已设计/结构已校验，视频未实测”。
