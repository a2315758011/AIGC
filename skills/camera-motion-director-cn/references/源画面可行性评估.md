# 源画面可行性评估

## 一、评估顺序

1. 确定视觉主体与必须保持可读的信息。
2. 判断景别、机位高度、拍摄角度和透视线。
3. 分离前景、中景、背景，确认各层是否能支撑视差。
4. 检查主体四周及运动方向上的画面余量。
5. 检查遮挡区域与运动后会暴露的隐藏表面。
6. 检查人物身份、手部、产品边缘、文字、Logo、玻璃/金属反射、屏幕 UI 和重复纹理。
7. 判断运动应由摄影机、主体、环境承担，还是保持静止。
8. 给出景深置信度、遮挡风险、几何风险与最大安全运动幅度。

## 二、景深证据

**高置信度**：前中后景层次明确；地面、道路、桌面、走廊等延伸平面可见；透视线一致；主体与背景分离；运动不会暴露关键未知表面。

**中置信度**：存在部分层次，但背景虚化较强；主体与家具/道具重叠；边缘空间或反射延续不确定。

**低置信度**：海报式平面构图；背景单一；长焦压缩明显；主体紧贴画面边缘；画面本身已有结构错误；正面图却要求展示侧面或背面。

## 三、边缘余量与遮挡

边缘余量是运动方向上可以合理延伸的画面信息，不等于单纯的空白像素。低余量情形包括：人物/商品贴边或被裁切；拉远需要补出身体、房间或桌面；摇摄方向超出图像边界；文字或 UI 位于边缘且必须可读。

平移、弧移和环绕都会改变遮挡关系。逐项检查：
- 人物背后是什么，是否有证据？
- 头发、手臂、家具、前景物体遮挡了什么？
- 侧移是否会暴露未提供的耳朵、手臂、产品接口、包装侧标或墙面？
- 运动是否会跨过人物侧脸/背面？
- 地面、桌面、墙面、镜面和阴影能否自然延续？

## 四、不同素材的安全倾向

| 素材 | 优先考虑 | 高风险动作 |
|---|---|---|
| 平面人物头像 | 固定、微推、轻微摇、移焦 | 大环绕、侧背面揭示 |
| 全身人物 | 轻推、短跟拍、有限横移 | 无路径跟随、复杂动作叠加 |
| 正面商品图 | 直推、微距滑动、小幅升降 | 凭空展示侧面/背面、360° |
| 多面商品图 | 小横移、小弧移 | 缺少背面证据却做完整环绕 |
| 走廊/道路 | 沿透视线推进、跟随 | 穿墙环绕、无依据横移 |
| 室内场景 | 固定、轻摇、直线推进 | 穿越家具/墙体、随意升降 |
| 分层风景 | 慢摇、小横移、缓慢推进 | 多轴高速飞行 |
| 插画/海报 | 平移、缩放、分层 2.5D | 当作完整真实 3D 空间环绕 |
| 屏幕/UI/键盘/网格 | 固定、正向推近、确定性合成 | 大角度斜绕、透视扭曲 |

## 五、风险处置

- 低风险：按计划执行，仍需审片。
- 中风险：缩小运动，明确起止画面，减少主体动作。
- 高风险：停止原幅度方案，给出最接近的可行替代；必要时要求补充多视角、深度图、分层图、参考视频或 3D 资产。
- 源图本身有畸变/错位：先修源图，不用运镜提示词掩盖。

替代原则：
- 大环绕 → 仅围绕可见表面的 5°-15°小弧移，角度仅作示例并需结合图像判断；
- 大横移 → 原地摇摄；
- 拉远 → 保持全景固定或先补宽画幅；
- 复杂跟拍 → 固定机位，让人物完成简单动作；
- 平面图真实环绕 → 分层 2.5D 或先重建多视角/3D。

## 六、漫剧专属空间保护

摄影机取景变化不改变人物世界坐标。分镜中已经确认的左右站位、人物距离、身体朝向、头部朝向、视线、轴线、动作状态、道具持有者和场景布局必须继承。

不得因为提示词里写了“环绕人物”“双人近景”就让角色自动靠近、换边、转身或瞬移。摄影机跨越 180° 轴线时必须有明确调度路径或切镜依据；否则维持原轴线。

摄影机遮挡与角色遮挡要分开描述。不能因为镜头移动就让被遮挡的人物/道具无过程显露，也不能让人物为了配合构图擅自走位。
