# 导演工作流与动态镜头合同（扩展研究）

本文件吸收独立导演技能的可迁移工作方法，不复制完整第三方 Skill，也不改变本仓库已有剧本/分镜主规则。

## 1. 新增导演级判断

参考：
- [wuwangzhang1216/DirectorSKILL](https://github.com/wuwangzhang1216/DirectorSKILL)（MIT，v2.1.0）
- [olegspiridonovdev-spec/cinematic-video-skill](https://github.com/olegspiridonovdev-spec/cinematic-video-skill)（MIT）
- [HiAPIAI/hiapi-image-to-video-camera-motion-skill](https://github.com/HiAPIAI/hiapi-image-to-video-camera-motion-skill)（根目录许可证未确认，本次仅研究，不复制正文）

吸收以下可迁移机制：
1. **先确定镜头功能，再决定运动**：镜头要让观众新增理解什么；没有新增信息时不增加运动。
2. **Blocking before framing**：人物/物体调度先于摄影机取景；摄影机不能为了构图改变人物世界位置。
3. **首帧是控制点**：图生视频大部分结构继承首帧；先把首帧构图、人物位置和场景几何修好，再消耗视频生成。
4. **镜头必须有时间变化**：写清开头状态、关键转折/动作节点、结束状态；不能只写“人物在走”“镜头很电影”。
5. **运动预算**：摄影机、主体、环境三类运动中，默认最多两类同时明显运动；三类都高幅度运动时拆镜或降低复杂度。
6. **连续性工程化**：身份、服装、场景锚点、光线方向、屏幕方向、人物站位和道具状态用可复用约束明确继承。
7. **失败诊断优先于重抽**：先分类缺陷和根因，再进行一次有针对性的修改；不以反复重写提示词替代诊断。

## 2. 动态镜头合同（每镜最小必填）

- 镜头故事功能；
- 开始画面状态；
- 一个主要动作/变化及其转折点；
- 摄影机运动类型、方向、幅度、速度节奏与动机，或明确固定；
- 主体动作与环境动作；
- 画面开始/结束时主体大小、位置和视线；
- 连续性锁定项；
- 结束状态；
- 风险与备选方案。

不强制每条短提示词写满摄影机参数；镜头合同供导演决策与质检，最终提示词按模型输入限制压缩。

## 3. 运动预算规则

三类运动：
- C：摄影机（位置、朝向、焦距/焦点）
- S：主体（人物、动物、车辆、商品）
- E：环境（雨、烟、布料、树叶、车流、背景群演）

默认最多两类显著运动。例如：
- C + S：跟拍人物行走，环境稳定；
- S + E：固定机位中人物转身，窗帘轻动；
- C + E：缓慢横移观察静态建筑，雨雪流动；
- C：纯摄影机运动展示商品。

如果 C/S/E 三类均需要显著运动，说明拆成两个镜头、降低其中一类幅度，或使用有明确控制能力的三维/轨迹生成流程。

## 4. 镜头失败分类（本技能的自有编号）

| 编号 | 缺陷 | 首要排查 |
|---|---|---|
| CM01 | 指定运镜未发生 | 模型控制面、提示词主次、运动幅度 |
| CM02 | 运动类型混淆 | 摇摄/横移、推轨/变焦、俯仰/升降 |
| CM03 | 摄影机路径突跳 | 关键帧间距、插值、速度曲线 |
| CM04 | 主体漂移/瞬移 | 世界坐标与运动预算 |
| CM05 | 透视/视差不一致 | 源图深度、相机位姿、几何条件 |
| CM06 | 隐藏表面凭空生成 | 多视角/深度/3D证据不足 |
| CM07 | 跟拍距离或构图丢失 | 主体路径与相机跟随约束 |
| CM08 | 轴线/屏幕方向破坏 | 场景调度与摄影机跨轴 |
| CM09 | 焦点错误/抽动 | 对焦目标与景深 |
| CM10 | 运动收尾失稳 | 减速曲线、结束帧、停留时间 |
| CM11 | 画面边缘拉伸/黑边 | 画幅余量与位移幅度 |
| CM12 | 纹理/身份闪烁 | 主体参考与模型稳定性 |

这些编号是本技能内部诊断码，不声称与第三方项目的 F1–F19 对应。

## 5. 风格与摄影参数

摄影机运动不能脱离镜头与画幅。需要时明确：
- 焦距或视角（FOV），以及为何选用；
- 景深/光圈感与焦点目标；
- 机位高度、镜头俯仰与主体视线；
- 快门/运动模糊风格（仅在模型或后期可控制时）；
- 画面头部/尾部主体尺度、留白和视线空间。

不要将“35mm”“180°快门”等摄影术语当作所有视频模型都能精确执行的参数。模型不支持时只作为风格提示，并标注其非确定性。
