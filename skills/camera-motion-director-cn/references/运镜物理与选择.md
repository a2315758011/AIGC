# 运镜物理与选择

## 一、先区分四类变化

| 类别 | 机理 | 典型动作 | 是否改变透视 |
|---|---|---|---|
| 机位旋转 | 摄影机位置基本不变，镜头转向改变 | 摇、俯仰、横滚 | 通常不产生由机位位移导致的视差 |
| 空间位移 | 摄影机在场景中移动 | 推拉、横移、升降、摇臂、跟拍、环绕 | 是，前后景相对位置发生变化 |
| 光学变化 | 摄影机位置不变，焦距/焦点改变 | 变焦、移焦 | 变焦改变视角与景深表现；移焦改变清晰平面 |
| 固定机位 | 摄影机不动 | 锁定镜头 | 否 |

特别注意：
- Dolly 与 Zoom 不能互换。推轨会改变近远景的相对大小；变焦主要改变视角与取景范围。
- Pan 与 Truck 不能互换。摇镜头是在原地转向；横移会改变遮挡关系和视差。
- Tilt 与 Pedestal 不能互换。俯仰是转动；升降是机位垂直移动。
- Rack focus 不是镜头移动，而是焦点从一个平面转移到另一个平面。

## 二、常用运动及其叙事目的

| 运镜 | 典型目的 | 使用前提 | 常见风险 |
|---|---|---|---|
| 固定/锁定 | 观察、压迫、庄重、让表演突出 | 构图已能表达信息 | 被误认为缺少设计 |
| 缓慢推进 | 亲密、重要性、紧张、发现 | 主体清楚，前方空间可支撑 | 面部/文字被放大后暴露瑕疵 |
| 缓慢拉远 | 孤立、交代环境、揭示关系 | 画面外空间有可靠素材 | 凭空补造背景或身体 |
| 水平摇摄 | 转移注意、展示相邻空间 | 起点和终点都存在 | 画面边缘内容被模型乱补 |
| 垂直俯仰 | 展示高度、由局部揭示整体 | 垂直空间连续 | 建筑线条倾斜、地平线漂移 |
| 横向移动 | 空间探索、前后景视差 | 有可辨认的景深层次 | 背景结构扭曲、人物漂移 |
| 升降 | 规模揭示、观察高度变化 | 地面/背景结构明确 | 人物比例、地平线和遮挡变化异常 |
| 摇臂 | 从近景升至全景、空间揭示 | 足够纵深与开放空间 | 新视角需要重建大量未知内容 |
| 弧移/环绕 | 展示立体关系、角色/商品观察 | 有侧面或多视角依据 | 凭空生成背面、脸型、产品结构 |
| 跟拍/跟随 | 维持动作连续、沉浸感 | 主体运动方向和路径明确 | 步态滑动、摄影机跟丢主体 |
| 前导镜头 | 主体向摄影机方向移动 | 主体路径、摄影机退让空间明确 | 透视关系不稳定 |
| 手持 | 纪实、紧张、临场 | 明确需要主观/纪实质感 | 无目的抖动、画面疲劳 |
| 微距滑动 | 材质、工艺、细节展示 | 细节清晰且有空间余量 | 表面纹理爬动、焦点失控 |
| 甩镜 | 强动作冲击、转场 | 起终点明确，允许运动模糊 | 模型生成随机模糊或隐性切镜 |
| 希区柯克变焦 | 眩晕、心理冲击 | 需同时反向推轨和变焦，且模型支持 | 只做普通变焦，效果不成立 |

## 三、组合规则

可控组合（仍需明确主次）：
- 轻推 + 轻微呼吸/眼神变化；
- 小弧移 + 受控材质反光；
- 侧向跟拍 + 简单步行动作；
- 固定镜头 + 蒸汽/雨/风等环境微动；
- 微距滑动 + 一次焦点转移。

高风险组合：
- 环绕 + 横移 + 变焦；
- 高速摄影机 + 复杂肢体动作；
- 摇臂 + 主体大幅转身；
- 多次反向变向 + 短时长；
- 甩镜 + 复杂环境运动；
- 多人对话中摄影机跨轴或绕过人物而未交代空间路径。

默认一个主导运动。辅助运动必须服务同一视觉目的，幅度和复杂度低于主运动。

## 四、运动幅度分级

- 极小：微漂移、轻微推近、轻微摇摄，构图基本不变。
- 小：运动可读，主体仍保持原有画面关系，适合多数单图 I2V 首测。
- 中：产生明显视差或角度变化，需要可靠的前中后景和边缘余量。
- 大：出现显著新视点/新空间，需要多视角、深度图、3D 或明确的相机控制能力。

角度不是万能指标。环绕角度必须结合主体遮挡、侧背面证据和镜头焦段判断；没有源图/多视角证据时，不承诺完整 180°/360°。

## 五、运动时间节奏

先给起始稳定帧，再完成主要运动，最后减速并稳定停留。以 5 秒镜头为例，可将前约 0.3-0.5 秒用于建立画面，中间约 3 秒用于主运动，最后约 0.7-1 秒用于停稳；这只是节奏参考，不是模型硬参数。

速度必须和路径一起描述：
- “从静止缓慢启动，匀速向左横移，最后平滑减速停在人物侧面”；
- “先稳定半秒，再沿走廊中轴缓慢推进，终点停在门口外侧”；
- “固定机位向上俯仰，从桌面细节停到墙面标识”。

不要只写“快一点”“丝滑一点”“电影感”。

## 六、选择决策

1. 观众需要新信息吗？不需要时固定镜头可能更好。
2. 新信息在画面中存在吗？不存在时不能靠运镜凭空创造。
3. 需要改变机位位置吗？若只需换取景方向，优先摇/俯仰；需要视差才用位移。
4. 源素材能支持吗？不能时缩小运动、补素材或改为 2.5D/3D。
5. 动作和运镜是否抢夺注意力？若是，降低其中一方复杂度。
6. 最终画面是否明确？没有可描述的终点，就不能算完成运镜设计。
