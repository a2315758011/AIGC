# 三维摄影机轨迹与预演工具研究

本类工具把导演描述变成可编辑、可预览、可导出的摄影机路径。它们不是纯提示词 Skill，但能补足自然语言难以精确表达的路径、速度、相机姿态与时序。

## 1. 工具对比

| 项目 | 类型 | 已核实能力 | 适合用途 | 采用建议 |
|---|---|---|---|---|
| [Emulsion](https://github.com/dennisonbertram/emulsion) | MIT；Three.js 分镜预演 Skill + Web 应用 | 场景物体/人物关键帧、摄影机位置/LookAt/FOV、跟随、轨迹导出 MP4、镜头/场景/素材库、QA | 漫剧站位与摄影机路径预演，输出视频模型运动参考 | 高优先级研究；作为可选预演工具，不强制安装 |
| [Generate-Camera-Trajectory](https://github.com/mbkizil/Generate-Camera-Trajectory) | 轨迹设计器 | LAMP/Auteur 运动原语、连续参数、相机 POV 预览、轨迹随机采样、JSON 配方、NPZ 位姿导出（OpenGL/Blender/OpenCV/COLMAP） | 标准轨迹、可重复路径、参数化镜头库 | 高优先级参考，吸收轨迹 DSL 和可复现设计 |

## 2. 轨迹数据模型

统一内部相机轨迹应至少包含：
- 时间戳 t；
- 相机位置 position；
- 相机朝向 rotation 或 look_at；
- 焦距/FOV；
- 插值方式（linear / eased / spline）；
- 速度/加速度或速度曲线；
- 坐标系声明（OpenCV / OpenGL / Blender / COLMAP）；
- 场景单位与 up 轴；
- 轨迹版本、来源和生成方式。

禁止混用不同坐标系而不做转换。OpenCV/Blender/OpenGL 的相机朝向和轴向约定可能不同，必须通过已知测试点验证转换。

## 3. 轨迹制作规则

1. 先确定主体/锚点的世界坐标，摄影机相对锚点规划路径。
2. 关键帧定义起始、主要变化点、终点，不只定义起点终点。
3. 路径曲线与时间曲线分离：可以保持路径不变而调整到达时间/速度。
4. 插值要检查位置连续、方向连续和 FOV 连续；避免 LookAt 目标突变。
5. 跟拍要区分“相机位置跟随”和“相机朝向跟随”；只锁其一或两者都锁须明确。
6. 结束时停稳，必要时加停留帧，便于后续剪辑。
7. 输出相机轨迹参考 MP4 时，使用中性几何/相机视锥 HUD，确认轨迹本身，不把内容风格混入运动参考。

## 4. 与 AIGC 漫剧工作流的关系

- 人物站位技能：给出人物和场景锚点世界坐标。
- 运镜导演技能：决定镜头意图、轨迹类型和时间节奏。
- 轨迹预演工具：将方案可视化成摄影机路径及运动参考片。
- 视频生成模型：根据首帧/角色参考/运动参考生成最终画面。
- 审片技能：比较计划轨迹与生成视频的方向、幅度、节奏、主体关系。

当前仓库仅登记这些工具和规则；不自动安装 Emulsion、Atlas 或其他第三方应用。安装/部署需要单独检查系统要求、API 成本和用户设备适配。
