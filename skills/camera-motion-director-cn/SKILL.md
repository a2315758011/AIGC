# 中文运镜导演与摄影机运动控制技能

## 目标与边界

把剧情意图和既定分镜转换成**可执行、可验证、与空间连续性兼容**的摄影机运动方案。运镜是叙事与观众视点控制，不是给每个镜头添加动态效果。

本技能负责：镜头运动选择、物理路径、运动幅度/速度/节奏、镜头起止构图、主体与摄影机关系、视频模型提示词适配、生成结果运镜质检。

本技能不负责重写剧本，不擅自改变人物世界坐标、人物关系、动作因果、道具状态、场景布局、景别定义或既有导演决定。需要分镜全流程时，配合 `storyboard-director-cn` 或 `manju-director-cn`；本技能只补充摄影机运动层。

## 触发场景

- 用户要求设计、修改、解释或审核某个镜头的运镜。
- 将静态分镜图/首帧转成图生视频。
- 将剧情动作编译成一镜到底的摄影机运动提示词。
- 多镜头序列需要统一镜头语言、轴线和视点连续性。
- 生成视频出现镜头乱晃、漂移、无意义环绕、人物位移、透视跳变或镜头运动不明显。

## 强制原则

1. **先确定镜头目的，再选择运动。** 每次运镜必须回答：观众要注意什么、镜头移动揭示什么、情绪或信息如何变化。没有明确目的时，固定镜头优先。
2. **摄影机运动与主体运动分开描述。** 摄影机的位移/旋转、人物的走位/转身、环境运动分别写清，禁止把人物移动伪装成镜头移动。
3. **区分物理机制。** 摇摄/俯仰/横滚是机位旋转；推拉/横移/升降/摇臂/跟拍/环绕是机位在空间中移动；变焦是焦距变化；移焦是焦平面变化。不得把推镜头写成变焦，也不得用“镜头旋转”含混代替轨迹。
4. **每镜只设一个主导摄影机运动。** 可有一个幅度更低的辅助动作，但只有在模型支持且运动逻辑不冲突时使用。短镜头不堆叠推、拉、摇、移、环绕、变焦和手持抖动。
5. **继承分镜空间状态。** 人物世界坐标、相互距离、身体朝向、视线、轴线、道具持有关系与场景结构不因摄影机取景变化而改变。景别变化不等于人物走位。
6. **先判断素材能否支持运动。** 单张平面图不能无依据揭示背面、隐藏肢体、商品背标或不存在的房间。大幅平移/环绕需要深度、额外视角、视频参考或 3D 重建证据。
7. **轨迹必须有边界。** 写明起点、终点、方向、相对主体的位置、运动幅度/角度、速度变化、结束构图；不能只写“电影感运镜”“镜头丝滑移动”。
8. **模型能力以真实接口为准。** 只有读取到具体模型/工具的参数 schema 或官方文档，才可使用对应的镜头预设、数值控制、负面提示词、首尾帧或多镜头参数。不得臆造参数。
9. **尊重生成证据。** 提示词写得完整不代表镜头已执行；只有检查真实视频才能判定运镜执行质量。

## 与现有站位规则协作

涉及多人站位、场景调度、走位路径、摄影机轴线或双人近景时，必须同时读取现有规则：`../storyboard-director-cn/references/人物站位与场景调度规则-V1.md`。该文件负责人物世界位置、场景锚点、走位链和轴线门禁；本技能只负责摄影机运动设计，不重复定义人物调度。若当前离线包没有该文件，明确报告缺失，并严格沿用本技能中的空间保护条款，不得假装已读取。

## 工作模式

- **设计模式**：给出镜头目的、运动选择、路径、时间节奏、风险和可直接使用的提示词。
- **图生视频模式**：先分析首帧的景深、遮挡、边缘余量和隐藏表面，再确定最大安全运动幅度。
- **序列模式**：先确定整段镜头语言总控，再逐镜分配运动；镜头间维持轴线、视线、人物位置与动作交接。
- **审片模式**：根据真实视频指出运动未执行、方向错误、透视变形、人物漂移、轴线破坏或收尾崩坏的具体时间段，并修正最早的根因。
- **模型适配模式**：根据模型实际输入字段，将同一导演方案转换成自然语言提示词或结构化相机参数。

## 执行流程

### 1. 锁定已知事实

读取当前分镜、参考图/首帧、场景布局、人物站位和目标模型信息。区分：
- 已由剧本/分镜/素材明确的事实；
- 从画面可见的事实；
- 合理但未证实的推断；
- 缺失或未知信息。

不要求用户重复提供当前上下文已有的内容。关键空间信息未知时，不得用精确距离或隐藏结构填空。

### 2. 明确镜头功能

从以下功能中选一个主功能，必要时补充次功能：
- 建立空间/交代关系；
- 跟随动作/保持人物视点；
- 揭示信息/从局部到整体；
- 靠近人物/加强情绪；
- 拉开距离/表现孤立；
- 检查产品/强调材质细节；
- 展示尺度/空间纵深；
- 制造压迫/不安；
- 客观观察/保持克制；
- 固定视点/让表演和环境承担运动。

### 3. 选择运动类型

先阅读 `references/运镜物理与选择.md`。判断需要的是旋转、空间位移、光学变化还是固定镜头。再根据剧情功能和素材条件选择，不按术语数量选择。

### 4. 检查源画面与空间可行性

图生视频任务必须阅读 `references/源画面可行性评估.md`。检查前/中/后景、透视线、地平线、画面边缘余量、遮挡、隐藏表面、人物身份/产品结构/文字和反射。给出安全幅度：极小、小、中、大，并说明证据。

### 5. 编写运镜执行单

每个镜头至少写清：

```yaml
shot_id: "镜头编号"
story_function: "镜头要传达的信息/情绪"
camera:
  start_position: "相对主体的起始位置；未知则写未知"
  end_position: "目标位置或目标构图"
  move_type: "static|pan|tilt|roll|dolly|truck|pedestal|crane|arc|orbit|tracking|follow|lead|zoom|rack_focus|handheld"
  direction: "明确方向"
  magnitude: "极小/小/中/大；必要时给有依据的角度或距离"
  speed_profile: "起始稳定、加速/匀速/减速、结束停稳"
  duration_seconds: null
  framing: "景别、机位高度、视角、主体在画面中的位置"
subject_motion: "人物/物体独立动作；无则写静止"
environment_motion: "环境独立运动；无则写静止"
focus_behavior: "锁焦/一次移焦/其他已确认行为"
continuity_locks:
  - "人物世界位置和相互距离"
  - "身体朝向、视线、动作与道具状态"
  - "场景结构、光线方向和轴线"
end_frame: "结束时观众实际看到的画面"
risk: "低/中/高"
fallback: "素材不支持时的更安全方案"
```

没有依据的角度、米数、速度数值或时间码写 `null/待确认`，不得伪造精度。

### 6. 编译模型提示词

阅读 `references/提示词编译与模型适配.md`。图生视频提示词优先写**变化内容**，不重复首帧已经确定的大段静态描述。推荐顺序：

1. 摄影机做什么（物理动作+方向+幅度）。
2. 摄影机与主体的相对关系如何保持。
3. 主体自己的动作。
4. 环境的辅助运动。
5. 焦点和画面稳定要求。
6. 运动如何减速、停稳以及最终构图。
7. 必要的连续性保护项。

输出中文导演说明；目标模型需要英文时，再提供对应英文提示词。负面提示词只在模型确实提供该字段时输出。

### 7. 生成前门禁

- 单张图片 + 大环绕/大幅横移/大幅拉远：先降低幅度或要求多视角/深度/3D 资源。
- 低景深/扁平插画/紧裁切：优先固定、轻推、轻摇、变焦或 2.5D 分层。
- 人物复杂动作 + 高速运镜：拆分动作或降低其中一方复杂度。
- 多人对话：摄影机运动不得改变既定站位、距离和轴线。
- 商品、屏幕、字幕、Logo、键盘等精细重复结构：优先正面、直线、小幅运动，保护可读性和几何。
- 模型参数未知：只给通用提示词，不编造 API 参数。

### 8. 生成后审片

生成后阅读 `references/运镜质量检查.md`。至少检查开头、中段、结尾；运动复杂或有穿帮风险时逐帧/抽帧检查。记录真实文件/链接、模型、提示词版本、检查范围和缺陷。修复时一次只改变一个主要变量。

## 运镜语言硬规则

- **推/拉（Dolly）**：摄影机沿镜头轴线靠近/远离主体，透视关系随位置变化。
- **摇（Pan）**：机位固定，水平转动镜头方向。
- **俯仰（Tilt）**：机位固定，垂直转动镜头方向。
- **横移（Truck）**：摄影机横向平移，形成前中后景视差。
- **升降（Pedestal）**：摄影机垂直平移，不等同于俯仰。
- **摇臂/升降弧线（Crane/Jib）**：摄影机沿垂直或弧线路径移动，常伴随重新取景。
- **环绕/弧移（Orbit/Arc）**：摄影机围绕主体改变方位；必须说明角度、方向和可见表面范围。
- **跟拍/前导（Tracking/Follow/Lead）**：明确摄影机在主体前、后、侧方或斜前/斜后，以及跟随距离。
- **变焦（Zoom）**：焦距变化，不产生真实机位视差。
- **移焦（Rack Focus）**：焦点从一个景深平面转移到另一个，不是摄影机移动。
- **手持（Handheld）**：受控的低幅度机位不稳定；不能等同于随机抖动。

## 交付格式

快速任务：镜头目的 → 运镜选择 → 可行性/风险 → 中文提示词 → 模型提示词。

复杂任务：先给导演总控，再逐镜给执行单与提示词，最后给连续性检查清单。审核任务：缺陷证据 → 根因 → 修正方案 → 修正后的完整运镜描述。

必须分别标记：
- 运镜方案已设计；
- 结构化计划已校验；
- 视频已真实生成；
- 视频已实际审片。

未完成的层级标记“未执行”，不得互相替代。

## 扩展导演规则（V1.1）

1. **镜头必须有时间变化**：写明开头状态、关键动作/转折点、结束状态。只写人物活动或“电影感”不构成镜头设计。
2. **运动预算**：摄影机、主体、环境三类运动默认最多两类同时显著运动。三类都需要大幅运动时，拆镜或降低其中一类复杂度。
3. **首帧是控制点**：图生视频优先修正首帧构图、站位、主体身份和场景几何，再生成运动。
4. **失败诊断优先于重抽**：先归类缺陷、确定最早根因，再只修改一个主要变量。
5. **镜头参数有条件使用**：焦距/FOV、景深、快门和运动模糊可以作为导演约束；只有目标模型真实支持时才视为可精确控制参数。

按需读取：
- `references/导演工作流与动态镜头合同.md`：镜头动机、头-转折-尾、运动预算和缺陷分类。
- `references/三维摄影机轨迹与预演工具.md`：三维相机关键帧、轨迹设计、坐标系和预演工具。
- `references/可控视频生成技术路线.md`：相机位姿、参考视频、文本、多视角与几何条件生成。
