# 中文运镜导演技能 V1.0.0

用于 AI 漫剧、短剧、图生视频和文生视频的摄影机运动设计、模型提示词编译与运镜审片。

## 能力

- 识别摄影机旋转、空间位移、光学变化和固定机位。
- 按剧情功能选择推拉摇移、升降、摇臂、弧移、环绕、跟拍、前导、微距滑动、手持、变焦和移焦。
- 评估单张首帧的景深、边缘余量、遮挡、隐藏表面和结构风险。
- 保护漫剧人物站位、距离、朝向、视线、轴线、动作和道具连续性。
- 生成中文导演执行单与模型可用提示词。
- 按真实模型能力适配参数，不虚构 API 字段。
- 使用 Python 校验器检查结构化计划，并用独立审片清单评估真实视频。

## 使用

1. 将整个 `camera-motion-director-cn` 目录作为一个技能导入。
2. 用户提供剧本/分镜、参考图或视频，并说明目标镜头。
3. 技能先分析镜头目的和素材可行性，再给出运镜执行单与提示词。
4. 有授权视频生成工具时才生成；有真实视频文件时才做视频审片。

## 校验

需要 Python 3.9+：

```bash
python scripts/validate_camera_move.py tests/运镜计划回归样例.json
```

回归文件是两个独立用例的集合，按顶层 key 分别提取对象后传给校验器；校验器只做静态字段与高风险组合检查，不代表视频真实执行。

## 边界

- 不重写剧本或覆盖原分镜技能。
- 单张图不承诺真实 180°/360° 空间重建。
- 不因双人近景、环绕或推镜提示擅自改变人物世界位置。
- 方案设计、结构校验、真实生成和视频审片分别报告。
