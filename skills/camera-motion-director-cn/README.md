# 中文运镜导演技能 V1.0.0

用于 AI 漫剧、短剧、图生视频和文生视频的摄影机运动设计、模型提示词编译与运镜审片。

## 能力
- 识别摄影机旋转、空间位移、光学变化和固定机位。
- 按剧情功能选择推拉摇移、升降、摇臂、弧移、环绕、跟拍、前导、微距滑动、手持、变焦和移焦。
- 评估单张首帧的景深、边缘余量、遮挡、隐藏表面和结构风险。
- 保护漫剧人物站位、距离、朝向、视线、轴线、动作和道具连续性。
- 生成中文导演执行单与模型可用提示词；按真实模型能力适配参数。
- 使用 Python 静态校验结构化计划，并用独立审片清单评估真实视频。\n- 参考专业导演工作流、动态镜头合同、三维轨迹编辑器及相机条件视频生成技术。

## 使用
1. 将整个 `camera-motion-director-cn` 目录作为一个技能导入。
2. 提供剧本/分镜、参考图或视频和目标镜头。
3. 技能先分析镜头目的与素材可行性，再给出运镜执行单和提示词。
4. 有授权视频生成工具时才生成；有真实视频文件时才做视频审片。

## 校验
需要 Python 3.9+：

```bash
python scripts/validate_camera_move.py tests/运镜计划回归样例.json --json
```

校验器支持单条计划或顶层包含多个命名用例的 JSON；回归文件包含一个正常缓推正例和一个缺少背面/深度证据的 360° 环绕反例。校验器只做静态字段与高风险组合检查，不代表视频真实执行。\n\n## 深度参考\n- `references/导演工作流与动态镜头合同.md`\n- `references/三维摄影机轨迹与预演工具.md`\n- `references/可控视频生成技术路线.md`
