# 真人影视安全分镜 Skill V1.0.0

专门处理 GPT 原生生图中的真人影视风格锁定、虚构暴力视觉风险诊断、非图像化电影表达、逐镜提示词编译和生成后检查。

## 快速调用

真人安全分镜

可直接附上剧本/分镜，并说明：“每镜单独生成真人影视仿实拍图；保留剧情事实，只转换不适合直观呈现的细节；生成后检查风格和连续性。”

## 主要文件
- SKILL.md：触发条件、执行流程、职责边界和调用指令。
- references/安全视觉转换矩阵-V1.md：按镜头功能选择合规视觉表达。
- references/真人影视视觉锁定规范-V1.md：真人演员与实拍摄影硬约束。
- SOURCE_LOCK.json：来源、版本与文件哈希登记。

## 协作
需要正式分镜结构时使用 storyboard-director-cn；打斗动作与能量特效使用 fight-impact-vfx-cn；摄影机运动使用 camera-motion-director-cn；跨专业统筹时使用 director-previs-cn。

## 验收边界
本技能只定义规则和提示词工作流。没有真实 GPT 图像生成与人工检查记录时，不得声称模型拦截率、人物一致性或真实成片质量已通过。
