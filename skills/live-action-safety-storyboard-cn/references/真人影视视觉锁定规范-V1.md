# 真人影视视觉锁定规范 V1

## 目标媒介
真人影视剧/仿实拍短剧，而非漫画、插画、动漫或游戏 CG。

## 主体真实感
- 真人演员面孔与真实人体比例。
- 自然皮肤纹理、毛发、布料、饰品和真实环境材质。
- 真实摄影机景深、焦点过渡、曝光和动态范围。
- 真实布光逻辑：主光、补光、轮廓光与环境反射相互一致。
- 允许局部后期合成能量、烟雾、粒子和光效，但合成效果应服从真实场景光照与遮挡。

## 镜头锁定
每个镜头明确景别、角度、焦点主体、摄影机位置和是否运动。静态图只表达该镜头的一个瞬间，不用一张图模拟多秒动作。

## 风格负面约束（按需）
No anime, no manga, no comic illustration, no painterly brushwork, no line art, no cel shading, no game character render, no plastic CGI skin, no exaggerated 3D look, no collage, no storyboard grid unless explicitly requested.

## 参考资产优先级
已批准角色母版/场景母版 > 当前项目视觉圣经 > 用户文字描述 > 模型自由发挥。若参考资产缺失，不得伪称角色一致性已锁定。

## 真人风格验收
1. 面部是否呈现真人演员而非绘制线条？
2. 皮肤、头发和衣物是否具有真实材质细节？
3. 光影、景深、反射和阴影是否服从同一摄影逻辑？
4. 是否错误出现动漫眼睛、描边、平涂或游戏 CG？
5. 后期魔法效果是否只是合成层，没有改变主体媒介？
6. 多镜头人物是否与批准参考资产相符？

出现风格错误时，优先修正媒介锁和参考资产，不要继续堆叠“8K、杰作、超精细”等形容词。
