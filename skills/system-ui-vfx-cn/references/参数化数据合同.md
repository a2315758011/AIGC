本文件提供本专业建议字段，正式接入前必须对齐项目 SCG/共享事实合同。不得创建与权威 SCG 冲突的第二套人物、场景、道具或时间状态。

## 3. UI 内容数据

```json
{
  "content_id": "CHARACTER_STATUS_01",
  "locale": "zh-CN",
  "title": "角色状态",
  "fields": [
    {"id": "level", "label": "等级", "value": 12, "unit": ""},
    {"id": "health", "label": "生命值", "value": 85, "unit": "%"},
    {"id": "mana", "label": "能量", "value": 62, "unit": "%"}
  ],
  "icon_refs": ["ICON_LEVEL", "ICON_HEALTH", "ICON_MANA"]
}
```

## 4. 字段约束

- effect_id、emitter_id、content_id、字段 id 和 icon_refs 必须稳定且不重复。
- 数值类型必须明确；不要把 12、"12" 和 "12%" 混成同一字段。
- 位置、旋转和缩放的坐标系必须写清楚；世界空间不能直接当屏幕像素使用。
- start_frame/end_frame/event_frame 必须使用项目 FPS 对应的帧编号。
- seed 必须是确定整数；固定时间步长不能由每帧实际卡顿时间决定。
- color_ramp、图标和字体必须有来源/许可证记录。
- occlusion_refs 缺失时，不得默认为没有遮挡；需明确写入 none_verified 或 pending。
