# 验收与失败诊断

## 1. 门禁

| 门禁 | 核验对象 | 通过标准 |
|---|---|---|
| G0 内容真值 | 文案/数值/单位/图标 | 与剧本或数据源逐字/逐值一致 |
| G1 分层结构 | 底板/边框/文字/图标/光效/粒子/遮挡 | 可分别修改和关闭 |
| G2 参数可控 | 颜色/字体/位置/尺寸/速度/粒子参数 | 修改参数只影响目标属性 |
| G3 时间确定 | 同 seed/时间/输入 | 关键帧重复一致 |
| G4 可读与安全区 | 人脸/对白/动作/平台 UI | 无关键遮挡、无裁字 |
| G5 Alpha | 编码/像素格式/解码帧 | 真实透明，边缘无明显黑/彩边 |
| G6 空间合成 | 锚点/透视/遮挡/跟踪 | 人物手部前后关系正确 |
| G7 跨镜连续 | effect_id/style_id/content_ref | 状态、外观和数值继承正确 |

## 2. 必查时刻

- 首帧：应为空或符合入场设计，不允许突然弹出残影。
- 入场中帧：边框/文字按预期顺序出现，无裁切和重叠。
- 稳定帧：所有文字可读，数值准确，主体视觉优先。
- 更新帧：只更新指定字段，不让整个面板闪烁或重排。
- 退场帧：无残留、无突然消失、无不完整字符。

粒子至少检查 spawn、peak、decay 三个阶段；空间绑定另查镜头移动前后关键帧。

## 3. 失败诊断

| 症状 | 常见根因 | 修复 |
|---|---|---|
| 中文缺字/方框 | 字体不含字形或云渲染器缺字体 | 更换有覆盖的字体并逐字检查 |
| 数字错误 | 文案硬编码或数据类型转换 | 重新绑定权威数据源 |
| 每镜 UI 变化 | 缺少稳定 ID/样式引用 | 固定 effect_id/style_id/continuity_group |
| 粒子重复渲染不同 | 随机源未固定或 timestep 不一致 | 固定 seed 和 fixed timestep |
| UI 穿过手掌 | 缺少 matte 或遮挡顺序错误 | 增加前景遮挡层/分层合成 |
| UI 随镜头漂移 | 坐标空间/锚点/跟踪错误 | 核对锚点和相机变换 |
| 黑底而非透明 | H.264 或 Alpha 丢失 | 改 ProRes 4444/VP9 Alpha/PNG 序列并解码验证 |
| 边缘黑边/彩边 | Alpha 预乘解释不匹配 | 检查 Straight/Premultiplied 模式 |
| 手机端掉帧 | DPR、粒子数、shader 过重 | 降 DPR/分辨率/粒子数量，降低 shader 复杂度 |
| 面板抢过人物 | 层级、亮度、尺寸过强 | 降低对比和面积，移动到负空间 |
| GPU 画面全黑 | shader 编译/上下文失败 | 查看编译日志，回退 Canvas/SVG |

## 4. 透明通道检查

不得只凭“导出完成”判定通过。至少确认：
1. 文件容器和视频编码符合 Alpha 交付目标。
2. ffprobe 报告像素格式或 Alpha 标记符合目标格式。
3. 解码一个稳定显示帧为 RGBA，检查透明像素确实存在。
4. 在深色、浅色和棋盘格背景上检查边缘。
5. 首尾帧符合空帧或动画设计，不残留。
6. 下游 NLE 的 Alpha Mode 与文件的 Straight/Premultiplied 类型一致。

## 5. 结果报告格式

每个资产分别报告：
- 已设计：内容和组件结构明确。
- 已生成代码：源码/参数已写出。
- 已运行预览：目标渲染器真实运行。
- 已导出：实际文件存在且规格正确。
- 已验 Alpha：透明通道解码检查通过。
- 已完成空间合成：人物锚点、透视和遮挡已实测。
- 已通过跨镜验收：相邻镜头状态继承通过。

不允许用一个状态覆盖其他状态。
