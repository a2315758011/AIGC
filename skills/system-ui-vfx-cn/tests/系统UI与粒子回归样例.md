# 系统 UI 与粒子回归样例

本表是验收用例定义；除非附有实际渲染证据，不代表目标平台已运行通过。

| 编号 | 输入/缺陷 | 预期判定 | 修复/通过标准 |
|---|---|---|---|
| U01 文字真值 | 属性面板显示等级/生命值与数据源不一致 | 不通过 | 所有文案和数值逐项匹配数据源 |
| U02 图层扁平化 | 面板、文字、图标和粒子被合成一张 PNG | 不通过 | 文字/图标/光效/粒子独立可编辑 |
| U03 属性控制 | 改主色却意外改变文字内容 | 不通过 | 参数按职责隔离，修改只影响目标字段 |
| U04 入场裁字 | 面板从左侧擦入，标题在边缘被切断 | 不通过 | 遮罩范围和文本框尺寸完整 |
| U05 状态更新闪屏 | 数值更新时整张 UI 先消失再出现 | 不通过 | 仅更新目标值，其他组件连续 |
| P01 随机漂移 | 相同粒子 seed 和时间生成不同关键帧 | 不通过 | 固定 PRNG、时间步长和输入 |
| P02 发射来源错误 | 火花从画面中心生成而非事件锚点 | 不通过 | 发射器绑定正确 anchor_ref/event_id |
| P03 生命周期缺失 | 粒子永久存在或突然消失 | 不通过 | 生命周期、淡出和销毁正确 |
| P04 粒子遮字 | 粒子覆盖系统面板的核心数值 | 不通过 | 粒子降层、避让或裁剪 |
| A01 Alpha 假透明 | H.264 黑底文件被标记为透明 | 不通过 | 使用真实 Alpha 编码并解码验证 |
| A02 Alpha 边缘 | 透明素材边缘出现明显黑边 | 不通过 | 正确设置/解释 Alpha Mode |
| S01 手部遮挡 | UI 全部盖在手指前方，但剧情要求部分位于手后 | 不通过 | 提供 matte/深度层并验证遮挡 |
| S02 锚点漂移 | 镜头轻微移动后 UI 离开掌心 | 不通过 | 跟踪/空间变换稳定，或降级为屏幕空间 |
| C01 跨镜重置 | 同一系统面板下一镜颜色、位置、数值重置 | 不通过 | 同 effect_id 和 continuity_group 继承状态 |
| M01 手机安全区 | 竖屏 UI 遮住脸或底部对白 | 不通过 | 重新布局并检查平台安全区 |
| R01 可复现 | 同 seed/同时间重复渲染 | 通过 | 关键帧像素一致或在声明容差内 |
| R02 独立控制 | 关闭粒子不影响面板文字和边框 | 通过 | 各层开关与参数独立 |
| R03 完整生命周期 | 入场、稳定、更新、退场均可读 | 通过 | 无闪现、残留、裁字和遮挡 |
