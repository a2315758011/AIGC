# AI 漫剧导演与分镜自检重写技能

**范围锁定：只做 AI 漫剧的剧情到分镜、漫剧角色/场景/道具资产、分镜审核、自动修复与完整修订终稿。**

## 必须读取的离线规则

1. **完整资产+分镜生产顺序**：`references/漫剧资产与分镜生产SOP-空间先行-V1.md`。用户要求完整漫剧资产与分镜时必须完整读取；正式分镜前必须先建立并锁定场景空间基线。用户只要求单项能力时遵守最小范围路由，不自动扩大任务。
2. **剧本转分镜**：`references/剧本转分镜指令.md`。收到剧本、需要制作或修改分镜时先读取完整原文；不得只读文件名、链接或概要。
3. **独立自检及完整重写**：`references/剧本转分镜自检指令.md`。每次输出正式分镜前都必须完整读取并应用这份规则，不需要用户再次提醒。
4. **漫剧人物/场景/道具资产**：`references/AIGC人物资产指令.md`。涉及素材生成、人物形象、角色三视图、场景及道具时读取；纯分镜文字任务不强制生成图片。

## 必须执行的核心闭环

1. **范围锁定**：识别用户本轮要完整资产+分镜，还是只做角色/场景/道具/分镜中的一个子项；只执行请求范围。
2. **原剧本锁定与资产需求盘点**：梳理人物、场次、地点、剧情事件、台词、转场、动作因果；建立角色、服装、场景、固定设施、家具、关键道具和状态变体的资产总账，分配稳定 ID，未知不补造。
3. **场景空间基线先行**：完整资产+分镜任务必须先调用/遵循 `scene-realism-director-cn`，锁定场景边界、门窗、固定设施、家具/大型道具占位、锚点、通道、可通行区域、支撑面和主要机位。达到 `SPACE_BASELINE_LOCKED` 前不得写正式逐镜分镜。
4. **角色与关键道具母版**：空间基线锁定后，制作独立人物/服装/道具资产并绑定稳定 ID 与场景锚点；大件尺寸改变布局时先更新空间基线并重新锁定。
5. **导演场面调度**：基于已批准场景和资产确定人物目标、动作节拍、入退场路径、停留点、视线、反应与机位覆盖；人物、身体动作和摄影机路径分开。
6. **完整分镜初稿**：严格执行当前 `剧本转分镜指令`；每镜写清机位、景别、人物世界位置/朝向/视线、动作起止、环境、道具状态、必要特效层次、视觉衔接与时长。
7. **独立自检**：使用 `剧本转分镜自检指令` 审查完整初稿，检查原剧本覆盖、对白、动作/物理因果、人物和服装一致性、场景方位、道具持有/可见性、镜头轴线、时长、镜头连续性和可生成性。
8. **自动修复与完整重写**：默认直接修复 P0/P1，处理受影响的前后镜头、关联资产与上下文；用户明确“只审不改”时例外。
9. **从头复检**：重新检查完整修订稿，直到 P0/P1 清零，或按原规则报告真实阻塞；连续两轮相同问题不得伪称已通过。
10. **文件交付**：环境支持文件创建时，按专业原文阶段门禁落盘需要的初稿、独立审核、完整修订终稿和最终复检记录；没有文件工具时提供完整终稿文本并说明限制。

### 分镜示意图规则（V2.8.8）

SVG 只用于记录人物位置、身体朝向、动作路径、道具位置/持有关系、前后景和镜头轴线，不负责表现漂亮画面、服装质感或面部表情。景别写在分镜正文中。示意图可使用简单符号、箭头、编号和图例；若无法清楚表达或会误导，**不要画该镜 SVG**，改用准确文字说明并标注未绘原因。不得为了每镜一图硬画火柴人。旧版任何要求 SVG 充当正式镜头画面、用 SVG 证明景别或视觉品质的条款均由本条覆盖。

## 漫剧资产任务

完整资产+分镜任务必须遵循空间先行 SOP：先做资产需求总账，再建立并锁定场景空间基线，之后才制作角色/服装/关键道具视觉母版并绑定到稳定锚点。场景基线不是最终每镜背景；它负责锁定拓扑、尺寸关系、通道、锚点和机位可达性。会影响空间占地的大件先用尺寸或代理占位表达，尺寸未知时保留未知。

需要人物、场景、道具或分层视觉资产时，按《AIGC人物资产指令》制作独立可用资产。不得用拼在一张展示图上的资产冒充可直接绑定的独立文件。没有图像工具或无实际成品时，不得声称资产已生成或验收。用户只要求单项分镜时，不自动生成整套资产；用户只要求单项资产时，不自动写分镜。

## 双人近景空间污染阻断（权威规则 V2.8.9）

写双人近景/过肩前景前必须读取人物既定站位、距离、机位和上一镜尾态。原本距离较远的两人，不得仅为同框而靠近、并肩或突然在镜头前景出现；改用单人近景加画外人物、合法正反打或保持距离的景别。发生无来源位移判 P0，修复后交付完整修订分镜并再次复检。SVG 仍只承担位置、动作、道具与轴线记录；画不清时可不画。

## 最终回答

默认优先交付**自检修复后的完整分镜终稿/实际资产**，不以冗长审核报告代替成品。仅在确有未解决问题、缺失素材或未做视频实际测试时，简要标出真实限制。不得把文本复检称为真实视频生成验收。

## 更新顺序

以仓库中三份同名原始指令为唯一权威正文。**先修订并验收原始指令，再核对原文 Git blob SHA，最后同步本技能 references、SKILL.md 和 SOURCE_LOCK.json**。详见 `skills/SKILL_UPDATE_PROTOCOL.md`。不得在源指令未审定前直接修改技能规则。

## 空间状态账本与镜头约束编译（V2.9.1）

开始写分镜前，在内部建立人物/道具/摄影机状态账本：人物位置与相对距离、身体/头部朝向、视线、动作起止；道具唯一 ID、持有者/哪只手、位置和状态；摄影机机位、轴线、画内外角色及遮挡。每项标记为原文明确、素材可证、推断或未知；未知不得补成事实，不得编造精确距离。

景别只改变摄影机可见范围，不改变人物世界坐标。远距离角色不得仅因“双人近景/过肩”提示而靠近或突然成为前景。无合法走位时优先单人近景、画外人物、正反打或真实可行的中远景。道具状态变化必须有可追踪动作事件。每镜开始状态→动作→结束状态，下一镜承接上一镜结束状态。

执行反例压力测试：远距离双人近景、左右换位、无动作进出画、道具无交接换手、视线错位、跨轴、动作首尾不一致。发现问题修复最早冲突镜头并复查前后镜，最终输出完整修订稿。内部表格或 SVG 可选且默认不输出；SVG 不是交付要求。

## 分镜导演推演（V2.10.1）

本技能聚焦分镜脚本，不替用户重写剧本。先拆视觉节拍，再设计镜头；检查观众信息、动作链、表演可见证据、镜头新增信息、景别/机位/轴线/视线可实现性和提示词负载。发现缺失桥接时只补必要的镜头表达，不凭空新增剧情事实。最终默认不输出 SVG 或内部分析图。


## 当前离线规则版本

V1.1.2 新增完整资产+分镜的空间先行门禁：资产盘点 → 场景空间基线 → 角色/道具母版 → 导演调度 → 正式分镜 → 独立质检。

本技能的剧本转分镜与独立自检规则已同步至 V2.10.6；精确来源 SHA 以 `SOURCE_LOCK.json` 为准。该技能是独立漫剧闭环快照，不随 GitHub 主分支更新自动改变。

V2.10.5 的空间约束与 V2.10.6 的表演连续性约束必须与上述完整原文一并执行：
- **人物站位与场面调度**：同场景坐标基准、固定锚点、世界位置与画面位置分离、身体/头部/视线分离、合法走位与摄影机轴线、跨镜状态继承。
- **场景基线与空间差量**：同场景建立唯一站位基线；未变化状态继承，只记录真实变化；人物方向、画面运动与摄影机运动分轨；距离/权力构图等启发式不得覆盖剧本事实。
- **场景拓扑与可信姿态推断**：镜面/玻璃/投影/重复单元/危险边界使用稳定锚点；姿态关键点保留置信度；未知数值和未验证的模型控制兼容性不得伪造。


## 跨生成段落面部表演连续性

- 角色面部在画面中可见且承担对白/反应时，不能只写“看着对方/继续说话”；必须写可观察的眉眼、视线、嘴唇/下颌、面部张力与情绪意图。
- 10 秒/15 秒等模型时长上限切段时，记录上一段尾态、下一段首态、段内推进与本段尾态。没有剧情触发，不得在切段时恢复中性脸。
- 有意扑克脸、压抑或克制是有效表演，不得为了避免僵尸脸擅自加戏。
- 使用 SCG `generation_segments` 或 `facial_performance` 时，必须按 storyboard-director-cn 当前 Skill 的要求运行结构化连续性校验器；当前环境无法访问校验器或未执行时标记 NOT_RUN，不得声称程序校验通过。
