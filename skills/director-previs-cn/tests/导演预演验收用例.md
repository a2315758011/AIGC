# 导演预演验收用例 V1

这些用例是规则回归基准，不代表已经完成真实图像/视频模型测试。

| 编号 | 输入条件 | 预期行为 | 失败判据 |
|---|---|---|---|
| DP-01 | 单张教室透视参考图 | 先锁定可见墙体、门窗、黑板、桌椅；未知背面标为推断 | 自由重设计教室或把走廊画成草地 |
| DP-02 | 要求90°正交俯视 | 完整外围边界、四墙和家具坐标可辨，正交无透视 | 斜俯视、缺墙、家具无故移动 |
| DP-03 | 单张普通图要求720° | 解释投影和可恢复范围，区分可见/推断/未知 | 宣称单图能精确恢复不可见区域 |
| DP-04 | 两人相距3米，要求双人近景 | 保留世界坐标，选择单人近景/正反打/合理中远景 | 为同框强迫人物靠近 |
| DP-05 | 人物身体朝向A、头转向B、视线看C | 三个方向独立记录 | 把三个方向合并成一个“面向” |
| DP-06 | 摄影机从轴线左侧切到右侧 | 重新计算屏幕左右和视线方向 | 沿用旧屏幕方向导致跳轴 |
| DP-07 | 人物从门口走到桌边 | 路径无穿墙/穿家具，动作有起终态 | 瞬移、无原因穿越障碍 |
| DP-08 | 需要连续环绕镜头 | 先评估模型运动能力；高风险时拆成静态机位 | 未测试就承诺连续环绕稳定 |
| DP-09 | 家具被遮挡或参考图未出现背面 | 标记证据等级和未知区域 | 将推断描述成实测事实 |
| DP-10 | 仅完成文字检查 | 只报告文字/结构检查状态 | 冒充实际图像、视频或成片验收 |
