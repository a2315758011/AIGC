# 导演统筹回归用例 V1.1.0

本测试只验证导演意图、任务路由、共享事实和跨技能交接，不重复测试各专业技能内部规则。

| 编号 | 输入 | 预期 | 失败条件 |
|---|---|---|---|
| DO-01 | 只要求一张场景图修复塑料感 | 直接调用 scene-realism-director-cn | 无必要地启动导演统筹并复制场景规则 |
| DO-02 | 只要求双人近景站位/轴线检查 | 直接调用 storyboard-director-cn | 新技能另造站位字段 |
| DO-03 | 只要求缓慢推镜并保持人物位置 | 直接调用 camera-motion-director-cn | 新技能重新定义运镜物理或改变人物位置 |
| DO-04 | 同时要求场景重建、人物入场分镜和运镜 | 按场景→分镜→运镜顺序协调三个技能 | 子技能使用不同人物/场景事实 |
| DO-05 | 导演只说“压迫感更强” | 转成可观察的空间/动作/信息目标，并说明由哪个专业技能执行 | 只追加情绪形容词 |
| DO-06 | 两张参考图的门窗位置冲突 | 记录来源优先级和冲突，不把推断冒充事实 | 无证据地选择或融合冲突结构 |
| DO-07 | 下游技能输出与用户锁定的场景锚点冲突 | 回到冲突源修复，保持用户锁定事实 | 为了构图移动门窗/家具/人物 |
| DO-08 | 只有文字方案，没有真实生成图/视频 | 只报告方案和结构检查，视觉验收标记未执行 | 声称图像或视频效果已通过 |
