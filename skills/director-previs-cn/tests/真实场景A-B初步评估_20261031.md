## 2. 现有能力审计：A组基线并不弱

读取当前 main 的：
- `storyboard-director-cn/SKILL.md`：V1.1.5，source V2.10.2。
- `storyboard-director-cn/references/人物站位与场景调度规则-V1.md`：V1.0.0。
- `分镜SCG数据契约-V1.md` 与 SCG 回归样例。

A组已有明确规则覆盖：
- 场景坐标系、门窗/讲台/黑板/桌排等固定锚点。
- 世界位置、人物姿态、画面位置、摄影机状态分离。
- 身体朝向、头部朝向、视线目标分开。
- 走位起点、路径、终点、触发原因和时间。
- 多人不得无来源重排；双人近景不得强迫人物靠近。
- 摄影机位置、朝向、高度、轴线、画面左右和跨镜连续性。
- SCG 结构校验和真实生成验收边界。

结论：普通教室入场、人物转头、站位、轴线与分镜连续性并不是现有技能的明显空白。新技能原1.0.0中的人物调度字段和相机轴线条款存在重复，不能把重复规则数量当作能力提升。

## 3. B组增量能力

新技能的有效增量应限制在：
1. 导演意图与观众信息控制。
2. 场景建筑拓扑、固定设施、家具布局和空间重建。
3. 俯视图、360°/720°全景的投影与证据分级。
4. 场景级摄影机覆盖/可达性预演。
5. 目标AI模型能力核验和静态关键帧→动态视频的分层验收。

已将技能收敛为 V1.0.1：普通人物站位、朝向、视线、走位、轴线和双人近景直接复用现有 storyboard-director-cn，不再建立第二套定义。

## 4. 静态干跑结论

本轮用同一教室参考素材与同一入场动作做规则干跑：

- A（仅现有分镜技能）：能够按已有空间锚点和人物调度规则处理门口入场、男主座位、朝向/视线和轴线；没有证据证明新技能在普通站位任务上必然提高结果。
- B（导演预演 + 现有分镜技能）：可先形成场景空间合同，明确房间边界、门外走廊、4×6桌椅真值、证据等级和机位覆盖，再交给现有分镜技能。
- 本轮能确认的是B提供了更显式的场景级交接资料；尚不能证明其真实图像/视频质量更高。

## 5. 图像生成尝试与排除

本轮图像生成工具两次输出了与目标教室场景无关的公寓A/B对比信息图，并擅自写入“新方案显著提升”等未经测试的结论。两张图均判定为任务偏离，**不纳入测试证据、不计分、不写入仓库素材**。因此本轮没有真实教室图像/视频模型结果。

## 6. 结论与后续门禁

- 规则层：发现并修正了新旧技能职责重叠。
- 静态资料层：已建立同一场景的结构化空间合同。
- 真实图像/视频层：未验证。
- 不得宣称A/B胜出或新技能已证明提升画面质量。

下一轮只有在同一参考资产、同一模型版本、同一生成参数下完成A/B图像/视频后，才按测试用例12项指标匿名评分。若B不能减少关键空间错误或提升可读性，应继续缩小技能范围，而不是继续加长规则。
