# 导演统筹工作流 A/B 实验协议 V1.0

实验编号：DIRECTOR-PREVIS-EVAL-20261101
适用技能：director-previs-cn V1.2.0
状态：协议已建立；真实工作流与图像/视频 A/B 尚未运行。

## 1. 实验目的

验证导演统筹是否真正减少跨专业技能漏调、共享事实丢失、专业输出冲突和返工；同时衡量它引入的额外调用、耗时与 Token 成本。

本实验不比较模型强弱，不以提示词长度作为质量，不把静态仓库测试当成画面质量证据。

预注册假设：
- H1：多专业任务中，导演统筹组 B 的关键事实遗漏数和跨技能冲突数低于直接调用组 A。
- H2：单一专业任务中，B 必须正确绕过导演统筹，避免增加不必要调用。
- H3：B 若显著增加耗时/成本，却没有减少错误或提高结果质量，则不接受其为默认工作流。

## 2. 对照组定义

### A 组：直接专业技能工作流（基线）

- 以测试集中的人工预先标注路由为准，直接调用对应专业技能。
- 每项专业技能都收到同一份原始用户任务和同一组原始参考素材。
- 多专业任务按规定顺序执行；后续技能可看到前序专业输出，但不提供由导演统筹生成的共享事实底稿。
- 不故意删减专业技能规则，不缩短输入，不使用弱化版提示词。

### B 组：导演统筹工作流

- 先调用 director-previs-cn。
- 由其生成导演意图、共享事实底稿、专业技能路由、各技能交接输入。
- 再调用与 A 组完全相同版本的专业技能，使用相同顺序和相同生成工具。
- 单一专业任务必须绕过 director-previs-cn，直接调用专业技能；误启动统筹视为路由错误。

A/B 唯一有意改变的变量是“是否先经过导演统筹并形成共享事实/交接包”。专业技能版本、原始任务、参考素材和生成环境不得变化。

## 3. 测试集与执行规模

机器可读测试集：tests/fixtures/导演统筹A-B实验数据集-V1.json。

- 路由/交接测试：10 个场景，A/B 各执行一次；其中单一专业任务用于验证绕过行为，多专业任务用于验证统筹价值。
- 静态图像实验：教室场景至少 5 组配对生成；若支持固定随机种子，A/B 使用相同种子。若不支持固定种子，每组独立生成并记录随机性，不得假称严格配对。
- 视频实验：静态图像实验完成后再执行；至少 3 组配对短视频，统一首帧/参考图、时长、分辨率、帧率、模型版本及运动强度。
- 以上属于小样本工程试验，不足以支持普遍性或统计显著性结论。结果接近、分歧较大或随机性高时，扩大样本再判断。

## 4. 必须锁定的控制变量

每次运行必须记录：
1. 目标模型/服务名称、精确版本或 API 版本、运行日期。
2. 参考图文件名与版本；不得在 A/B 之间更换或增删参考图。
3. 画幅、分辨率、时长、帧率、采样器、步数、CFG/引导强度、随机种子（若接口支持）。
4. 角色资产、服装、场景资产、原始剧情动作与用户硬约束。
5. 图像/视频生成工具版本、工作流文件哈希、提示词版本。
6. 每次专业技能调用、重试、返工、Token/费用（可取得时）和端到端耗时。

如果 A/B 使用了不同模型、不同参考图或不同生成参数，该轮视觉质量比较作废，只保留流程观察数据。

## 6. 执行顺序

1. 校验测试集、素材版本和硬约束，生成运行 ID。
2. 先执行 10 个路由/交接场景，保存 A/B 原始输出、调用顺序、耗时和事实清单。
3. 对多专业任务逐项标注：漏调技能、错误调用、事实遗漏、事实矛盾、重复规则、返工轮数。
4. 运行静态图像 A/B；每个样本保留原始输出、模型参数和生成元数据。
5. 将 A/B 文件名替换为随机盲码，随机化左右/先后顺序；评审者不知道组别。
6. 至少 2 名独立评审分别完成硬约束检查、维度评分和配对偏好判断；3 名更佳。评审者不得是该轮提示词/输出的唯一作者。
7. 先独立打分，再讨论分歧。记录每名评审的原始分数；不能只保留协商后的平均分。
8. 若有条件，可增加独立多模态模型评分，但必须作为辅助结果，并与人工评审一致性对照；不能单独作为最终放行依据。
9. 汇总结果，按预注册门槛判定 B 胜、A 胜或无明确差异；不得因结果不理想而事后修改评分权重。

## 7. 指标定义

### 流程指标（主要）

- 路由准确率：实际调用集合与人工标注必需技能集合的匹配程度。
- 漏调数：缺少的必需专业技能数。
- 误调数：不必要调用的专业技能数。
- 关键事实遗漏数：最终输出未保留或错误改写的锁定事实数。
- 跨技能冲突数：场景坐标、人物位置/朝向、道具状态、时间或摄影机事实互相矛盾的数量。
- 返工轮数：因技能交接错误而重新执行的次数。
- 端到端耗时、调用次数、Token/费用：分别统计导演层和专业技能层，不隐藏额外成本。

### 视觉指标（次要）

按视觉评分量表记录硬约束通过率、分维度分数、局部错误位置/时间码和盲评配对胜负。不得只用“更漂亮”作为结论。

## 8. 预注册判定门槛

B 组只有同时满足以下条件，才可判定为“值得默认启用”：

1. P0 硬约束通过率不低于 A 组；教室测试中任何 4×6/24 套桌椅、门外走廊、男主座位、教师讲台等核心事实错误均为 P0。
2. 多专业任务的“关键事实遗漏 + 跨技能冲突”合计至少降低 20%，或综合盲评分提高至少 0.5/4 分。
3. 单一专业任务没有新增 director-previs 误调用。
4. 额外端到端耗时和 Token/费用分别报告；若增加超过 25% 且质量/错误率未达到上述改善，不判 B 胜。
5. 至少 2 名独立评审完成；只有单人评审时，结果标记为初步观察，不得写成独立验收通过。

小样本 5 组图像配对若 B 至少赢 4 组，只能记为“初步偏好信号”，不能宣称统计显著或普遍提升。

## 9. 失败分级与停止条件

- P0：违反用户锁定事实、空间拓扑、物体数量、人物关键位置/动作因果，或出现不可接受的物理错误。直接判该样本失败。
- P1：跨镜连续性、材质/光线、构图或运动执行存在明显缺陷，需要返工。
- P2：不影响理解的审美偏好或轻微瑕疵。

出现模型/参数不一致、参考素材不一致、评审者获知 A/B 组别、输出文件缺失或生成元数据无法追溯时，停止该轮比较并标记 INVALID，不用主观印象补齐数据。
