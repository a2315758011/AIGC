# 场景空间保真与全景重建

## 1. 证据分级

对每个空间元素标记：
- A：原始图像/图纸明确可见。
- B：多张参考资料相互印证。
- C：由建筑连接关系推断，但无直接画面证据。
- D：未知，不得补写成事实。

对 A/B 元素保持原样；C 元素可用于形成可解释的重建候选；D 元素必须保留不确定性。

## 2. 空间拓扑优先

重建顺序：
1. 外围轮廓和墙体连接。
2. 门、窗、走廊、楼梯和可通行开口。
3. 固定设施（黑板、讲台、柜体、暖气、管线等）。
4. 大型家具及其朝向。
5. 可移动家具、道具和装饰。
6. 材质、纹理、灯光和细节。

不得先生成漂亮室内图，再把不符合原图的结构解释为“艺术处理”。

## 3. 坐标与尺度

建议定义右手坐标系：X 为场景水平向右，Y 为场景纵深，Z 为高度；原点选择一个稳定墙角或门洞基准点。若参考图无法建立真实尺寸，使用归一化坐标（0–1）并明确标注“比例坐标，非实测米制”。

家具记录中心点、长宽高、旋转角和可移动状态。未知尺寸不得伪造。相对位置比猜测精确尺寸更重要。

## 4. 俯视图验收

必须检查：
- 完整四周边界及墙角是否入画。
- 墙体厚度、门窗洞口和连接关系是否合理。
- 固定设施、家具是否全部保留且坐标未漂移。
- 门扇开启方向、通道净宽和家具碰撞。
- 90°正交俯视：不得出现明显透视收敛、立面透视或斜俯视。
- 遮挡物是否合理表达；必要时采用墙体剖切/透明显示，但不得误导墙体结构。

## 5. 360°/720°全景验收

先说明投影：等距柱状投影（水平 360°、垂直 180°）是常见球面全景；“720°”在不同工作流中可能指水平+垂直全向观察，也可能只是产品术语。必须明确实际覆盖角度、投影和输出格式，不能仅凭标签判断。

全景重建需验证：
- 水平 360°是否连续闭合。
- 垂直视域是否覆盖需要的天顶和地面。
- 相邻区域建筑线条、地面纹理、墙角、门窗位置是否一致。
- 接缝是否重复、拉伸、镜像、重影或断裂。
- 近景物体与远景的视差是否合理。
- 所有方位的光源方向和阴影逻辑是否一致。

如果素材只有单张普通透视图，背后空间通常无法唯一确定。应把可见区域作为高置信度重建，把不可见区域作为低置信度候选，不得宣称从单张图精确恢复真实 720°空间。

## 6. 冗余与安全边界

只有用户提出时才增加指定的视野冗余。冗余应通过扩展画布/视域实现，不得放大前景主体、改变家具尺寸或遮挡主要观察区域。交付时说明冗余比例的计算基准（画面宽高、角度或边缘留白）。
