# 导演意图与技能交接协议

## 1. 导演意图不是形容词

导演简报必须能指导下游选择和验收：场面目的、观众信息、人物关系变化、可见事件、视觉重点和结束状态。不得用“电影感、史诗、唯美、压迫感”替代可观察事件。

## 2. 专业技能边界

- 场景真实性：`scene-realism-director-cn` 负责建筑/室内外拓扑、空间功能、透视、物理接触、光材质、参考图保真、俯视/全景。
- 正式分镜与人物调度：`storyboard-director-cn` 负责逐镜设计、人物世界位置、身体/头部/视线、走位、轴线和跨镜连续性。
- 打斗动作与打击感特效：`fight-impact-vfx-cn` 负责攻防因果、接触/受击、力量传递、打击节奏、命中特效、环境反馈与声画同步。其当前 SOURCE_LOCK 状态为 `authored_pending_review`，不能描述为已通过真实视频验收。
- 摄影机运镜：`camera-motion-director-cn` 负责推拉摇移、跟拍、环绕、轨迹/速度、图生视频运镜与运镜审片。

## 3. 共享事实底稿

只维护一份共享事实：剧情动作与时序、人物身份/服装/道具状态、场景 ID/参考版本/固定锚点、用户锁定空间关系、画幅/时长/目标模型、未知项与推断项。各专业技能收到同一份事实；任何输出不得无理由覆盖。

## 4. 交接顺序

1. 导演意图简报与共享事实。
2. 场景真实性/空间骨架（需要时）。
3. 打斗动作因果/受力方案（有打斗时）。
4. 人物调度与正式分镜。
5. 摄影机运镜（需要时）。
6. 跨技能一致性检查。
7. 真实图像/视频和成片独立验收。

单一领域任务直接调用对应技能，不加载导演统筹；无打斗动作时跳过 fight-impact-vfx。

## 5. 冲突优先级

1. 用户明确要求和已批准项目事实。
2. 原始参考图、已验收母版和有来源的尺寸/空间数据。
3. 各专业技能权威规则。
4. 可解释的导演推断。
5. 模型自由发挥。

低优先级内容不得覆盖高优先级事实。无法解决时标记未知/待决定，不擅自猜测。
