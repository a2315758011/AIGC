# AI预演与质量门禁

## 1. 能力先行

先核实目标模型/工具实际支持的输入：
- 参考图数量与绑定方式。
- 首帧/尾帧控制。
- 多镜头/分段生成。
- 镜头运动控制。
- 角色参考或主体一致性。
- 画幅、时长、分辨率和音频能力。

不支持的控制不得写成硬指令；应改用可执行替代方案或标注无法保证。

## 2. 先静态后动态

高风险场景按以下顺序：
1. 场景空间关键帧。
2. 人物站位和视线关键帧。
3. 摄影机机位关键帧。
4. 对照场景合同检查静态图。
5. 静态通过后生成短动作视频。
6. 检查动作起止、身份、服装、道具、空间和镜头运动。
7. 修复关键帧后再重生成视频，不以反复抽卡代替定位。

## 3. 失败分类

- 空间漂移：建筑、门窗、家具位置改变。
- 人物漂移：身份、体型、服装或人数变化。
- 调度错误：站位、距离、朝向、路径或终态不符。
- 摄影错误：景别与距离不匹配、轴线错误、画面遮挡。
- 动作错误：动作缺步骤、因果断裂、手部/道具状态错误。
- 时间错误：动作超时、并行/串行关系错误。
- 风格错误：光线、色彩、材质与导演方案不一致。
- 模型能力错误：要求了目标工具没有的控制能力。

每类失败记录证据、最早出现位置、根因假设、最低成本修复和复测结果。

## 4. 验收层级

L0 规则读取：相关源规则和项目素材确实读取。
L1 静态空间：结构、家具、人物位置符合合同。
L2 预演：机位、视差、通行路径和遮挡符合物理空间。
L3 动态视频：人物动作、摄影机运动、身份和连续性可用。
L4 成片：剪辑、声音、节奏和完整播放体验通过。

每层单独报告。L0/L1通过不能冒充L3/L4通过；没有实际生成素材时标记“未执行”，不写“通过”。

## 5. 最低成本修复原则

先修最早的错误来源：场景资产错误先修场景；人物坐标错误先修空间合同；静态关键帧错误先修关键帧；仅在静态基准正确后才修视频运动提示词。不要用更长的提示词掩盖资产和几何问题。
