# 导演预演与场景空间技能

适用：场面导演意图、建筑/场景空间重建、俯视图、360°/720°全景、环境保真和场景级机位覆盖预演。

## 技能分工
- 本技能：场面意图、空间拓扑、场景重建、全景/俯视、场景级机位覆盖。
- `storyboard-director-cn`：正式逐镜分镜、人物站位/朝向/视线、走位、轴线、连续性和自检修复。
- `camera-motion-director-cn`：推拉摇移、跟拍、环绕、运动轨迹、速度节奏、视频模型适配与运镜审片。

## 文件
- SKILL.md：主入口、调用边界与工作流。
- references/导演空间决策方法.md：场面目标与空间表达。
- references/场景空间保真与全景重建.md：空间拓扑、俯视图、360°/720°全景。
- references/人物调度与摄影机设计.md：与现有分镜/运镜技能的交接，不重复定义。
- references/AI预演与质量门禁.md：静态空间、动态视频与分层验收。
- tests/：规则用例、真实场景A/B基准和空间合同夹具。
- SOURCE_LOCK.json：上游来源、许可、文件 SHA 与验证状态。
