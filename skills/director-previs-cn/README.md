# 导演预演与空间调度技能

适用：导演意图、场景空间保真、人物调度、摄影机预演、俯视图/全景重建和 AI 预演质量控制。

## 文件
- SKILL.md：主入口与职责边界。
- references/导演空间决策方法.md：戏剧目标与空间关系。
- references/场景空间保真与全景重建.md：场景坐标、俯视图、360°/720°全景。
- references/人物调度与摄影机设计.md：站位、朝向、视线、行动路线和机位。
- references/AI预演与质量门禁.md：静态关键帧、动态视频与分层验收。
- tests/导演预演验收用例.md：10 项规则回归用例。
- SOURCE_LOCK.json：上游来源、许可、文件 SHA 与验证状态。

## 使用边界
本技能不替代仓库现有的漫剧导演与分镜导演技能。需要正式分镜时，将已确认的导演空间合同交接给现有分镜技能。
