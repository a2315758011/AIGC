## 与现有仓库对照
现有主规则 V2.10.1 已记录人物区域/屏幕侧、相对距离、身体/头部朝向、视线目标、姿态、摄影机区域和镜头起止状态；明确景别不改变人物世界位置、远距离人物不得为双人近景无依据靠近。SCG 已区分实体存在、可见、遮挡，状态变化由事件授权。本轮增量是把场景局部坐标、固定锚点、走位路径、屏幕投影与摄影机状态整理为可复用专项操作规则。

## 采纳/不采纳
| 方法 | 决策 | 理由 |
|---|---|---|
| 场景坐标系与固定锚点 | 采纳 | 可复现，补足场景定位依据 |
| 世界位置与画面左右分离 | 强化 | 避免换机位造成错误换位 |
| 身体/头部/视线分开记录 | 强化 | 避免朝向语义混淆 |
| 起点—路径—终点走位链 | 采纳 | 检查瞬移与穿障碍 |
| 站位图与逐镜摄影机图分离 | 采纳 | 避免站位图锁死镜头 |
| 固定 CAM1~CAM4 模板 | 不采纳 | 机位由场景和镜头任务决定 |
| 每场权力关系必须变化 | 不采纳 | 过场可能没有权力变化 |
| 强制 2×2/3×3 站位拼图 | 不采纳 | 容易误导空间且非必要 |
| 仅用数字坐标写投喂词 | 不采纳 | 模型支持未知，不利于人工审阅 |

## 第二轮扩大搜集（2026-10-31）

本轮在第一轮 5 个候选基础上扩大到导演技能、影视制作 Agent Skills、Blender 预演、浏览器/桌面 3D 预演和自动几何校验。累计扫描约 30 个独立仓库/候选；对下列重点来源读取了具体 Skill、参考文件、验证脚本或测试。工具类仓库只作为方法/能力参考，不等同于可直接安装的 Skill。

### A. 直接值得吸收的导演/站位技能

1. **DirectorSKILL** — https://github.com/wuwangzhang1216/DirectorSKILL — MIT。重点：references/blocking-and-staging.md、continuity-bible.md。吸收人际距离区间、距离变化的时间表达、身高/前景/出口等权力几何、人物移动与静止关系；距离阈值仅作启发式，不作为固定硬规则。
2. **OmniAiLab AI Director** — https://github.com/tomatoparkdao/omniailab-ai-director — MIT。重点：references/BLOCKING SKILL.md。吸收一场景一份站位基线、未变化人物锁定、逐镜只更新差量、坐标/姿势/路径/支撑/遮挡校验。拒绝其平台专属字段和固定数值约束直接进入通用提示词。
3. **Narrative Film Direction** — https://github.com/Nagacash/narrative-film-direction — Skill 元数据标注 CC-BY-4.0（不是 MIT）。重点：SKILL.md、screen-direction.md、coverage-protocol.md。吸收主镜头建立地理、反打轴线、视线方向、反打背景预先定义、逐项变化诊断。主镜头先行、30°规则和5–8秒实践建议按场景/模型适用，不设成全局强制。
4. **NolanX Scene Blocking / Dialogue Performance / Axis Match** — https://github.com/nolanx-ai/nolanx.ai — 仓库 MIT。吸收人物移动需要有目标/压力/发现/权力变化依据，人物路径与摄影机路径分开，台词对象与身体行为/视线结合，越轴要有可读桥接。该项目的站位 Skill 偏短，作为补充，不视为完整空间求解器。
5. **Film Production Skills** — https://github.com/zhangzhangco/film-production-skills — MIT。重点：skills/plan-camera-shots/SKILL.md、references/field-guide.md。吸收空间基线、镜头段 start/action path/end state、稳定 segment ID、预检无效动作与不可达机位。
6. **AI Film Skills** — https://github.com/62656456/ai-film-skills — Apache-2.0。重点：framing-and-axis.md、shot-design-engine.md、experimental/whitebox-previs-executor。吸收世界状态与画面投影分离、摄影机中心/朝向/滚转分开、真实路径几何、白模预演与严格 MP4 验收边界。实验性白模执行器不能视为所有动作/模型都支持。
7. **Scenario Agent Skills** — https://github.com/scenario-labs/skills — 仓库 MIT。重点：scenario-blender-previs-storyboard、scenario-blender-blockout。吸收故事预演与 render-to-real 视频指导预演的区别、度量尺度、人物脚底根节点、逐镜摄影机、俯视路径图、遮挡/轴线/视线审计、接触表与同步对照。其具体 Blender 版本/插件依赖不自动成为本项目依赖。
8. **SSC 影视工业全链路** — https://github.com/yzsp-studio/ssc — MIT。重点：ssc/SKILL.md。吸收空间真值、XYZ 键名坐标、人物数量/角色引用锁、舞台定位与分镜引用映射、跨任务 handoff。拒绝固定 100×100 画布、强制 3×3 宫格、固定颜色/模型参数和每个制作阶段都必须弹窗等项目专属约束。
9. **Short Drama Prompt Director** — https://github.com/zouchenzhen/short-drama-prompt-director — MIT。吸收可复现的 P0/P1/P2 QA、生成前结构校验和独立回归测试；它不是专门的 3D blocking 引擎，不复制其平台提示词参数。

## 第二轮归纳出的增量规则

1. 场景级站位基线 + 每镜差量更新；未声明移动的人物继承原位。
2. 场景拥有演员/道具布局，镜头拥有摄影机；多角度覆盖不重摆人物。
3. 身体朝向、头部朝向、视线目标、对白对象、移动向量、屏幕方向、摄影机向量分别记录。
4. 人物与摄影机路径分开进行可达性/碰撞检查；门洞、支撑、地面接触和遮挡进入预检。
5. 距离区间、权力几何、主镜头先行是可选启发式，不成为强制数值和统一模板。
6. 站位质量按文字计划、结构化几何、白模预演、正式视频四层报告；不能跨层声称通过。
7. 有明确地理建立需求时先批准主镜头/空间参考，再设计反打；未定义的反打背景不得由模型随意补造。
8. 说话对象不等于视线目标；画外听者不等于人物消失。
