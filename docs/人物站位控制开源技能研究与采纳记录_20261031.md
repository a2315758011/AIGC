## 与现有仓库对照
现有主规则 V2.10.1 已记录人物区域/屏幕侧、相对距离、身体/头部朝向、视线目标、姿态、摄影机区域和镜头起止状态；明确景别不改变人物世界位置、远距离人物不得为双人近景无依据靠近。SCG 已区分实体存在、可见、遮挡，状态变化由事件授权。本轮增量是把场景局部坐标、固定锚点、走位路径、屏幕投影与摄影机状态整理为可复用专项操作规则。

## 采纳/不采纳
| 方法 | 决策 | 理由 |
|---|---|---|
| 场景坐标系与固定锚点 | 采纳 | 可复现，补足场景定位依据 |
| 世界位置与画面左右分离 | 强化 | 避免换机位造成错误换位 |
| 身体/头部/视线分开记录 | 强化 | 避免朝向语义混淆 |
| 起点—路径—终点走位链 | 采纳 | 检查瞬移与穿障碍 |
| 站位图与逐镜摄影机图分离 | 采纳 | 避免站位图锁死镜头 |
| 固定 CAM1~CAM4 模板 | 不采纳 | 机位由场景和镜头任务决定 |
| 每场权力关系必须变化 | 不采纳 | 过场可能没有权力变化 |
| 强制 2×2/3×3 站位拼图 | 不采纳 | 容易误导空间且非必要 |
| 仅用数字坐标写投喂词 | 不采纳 | 模型支持未知，不利于人工审阅 |
