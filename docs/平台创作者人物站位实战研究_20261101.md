# 各平台漫剧创作者人物站位实战研究（第一批）
日期：2026-11-01｜主题：人物站位、多人同框、场景空间、走位、反打轴线、预演和跨片段衔接。

## 结论
创作者公开方法主要汇聚为三条路线：
1. **俯视场景图 + 文字站位双锚**：图表达整体拓扑，文字逐个绑定角色 ID、位置、朝向、动作、道具和机位。
2. **3D 白模/导演台预演**：先放置人物代理、姿态、道具和摄影机，再输出参考帧/运动参考。
3. **场景多视图/全景 + 首尾帧续接**：由已确认场景扩展视角/俯视图，跨片段使用真实合格末帧作为下一段起始参考。

这三条路线不是互斥的。简单镜头不必强制上 3D；多人同框用俯视布局+文字 ID；复杂走位/反打/多机位升级白模预演；跨片段动作再使用末帧续接并检查中间帧。

### 3. Ksr 桑（观猹学社、TapNow、西瓜视频）

## 反例与风险
1. 俯视图/全景图可能透视畸变、扩图补造、角色ID混淆或造成2D穿模。
2. 文字坐标不是物理约束，必须做目标模型A/B测试。
3. 3D导演台必须把角色身份、场景锚点、相机预览、错误反馈一体化。
4. 场景锁定与人物锁定是两件事，不能互相替代。
5. 末帧续接不等于动作连续；检查首帧、中段、尾帧和切点。
6. 不采纳“零抽卡、一次锁死、完全控制”等宣传语作为技术结论。

## 写入正式规则
人物站位专项规则升级到 V1.3.0：
- 创作者方法采用 E0-E3 证据分级，播放量/粉丝数只用于发现账号。
- 形成俯视图+文字、3D白模/导演台、场景多视图/全景+首尾帧三条工作模式。
- 按空间风险选择模式，不强制每镜上3D。
- 参考图职责和角色ID必须对应；全景/俯视派生图须对照原图。
- 白模与成片并排对照；未对照不得声称模型服从。
- 末帧续接检查中间动作；返修优先定点补丁。
