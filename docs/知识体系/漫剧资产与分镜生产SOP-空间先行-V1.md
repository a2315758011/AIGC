# 漫剧资产与分镜生产 SOP（空间先行）

版本：V1.0.0  
适用范围：用户提供剧本，并要求完整漫剧人物/场景/道具资产与正式分镜；或明确要求从创意到成片的完整制作。  
权威关系：本文件定义跨技能生产顺序；专业细节仍以对应 Skill、原始指令、references 与 SOURCE_LOCK 为准。

## 0. 核心原则与范围路由

**先锁空间事实，再制作正式分镜。** 分镜不能替场景补造墙体、门窗、桌椅、通道、人物距离或道具位置。景别只改变摄影机取景，不改变人物在世界中的坐标。

完整能力库不代表每次全量执行。先按用户本轮交付范围选择最小技能组合：

| 用户目标 | 主入口 | 必要依赖 | 本次不自动做 |
|---|---|---|---|
| 只做一个角色/道具资产 | `AIGC人物资产指令` | 已批准身份、服装、尺寸与参考 | 场景重建、分镜、视频 |
| 只做场景空间/真实性 | `scene-realism-director-cn` | 用户参考图、已知尺寸和空间用途 | 正式分镜、角色资产、视频 |
| 只写/审查正式分镜 | `storyboard-director-cn` | 已批准场景、人物、道具事实；其内置导演推演和独立质检 | 自动生成整套资产、视频 |
| 完整人物/场景/道具资产 + 正式分镜 | `manju-director-cn` | 本 SOP；场景空间基线必须先于正式分镜 | 未经要求的视频、剪辑和漫画出版 |
| 从创意/剧本一路做到成片，或复杂跨专业统筹 | `director-previs-cn` 外层统筹 | 按阶段调用场景、资产、分镜、运镜、视频、特效和后期技能 | 不另写一份竞争性分镜稿 |

导演职责不等于每次都要额外加载第二个导演总控：普通正式分镜由 `storyboard-director-cn` 内置导演推演承担；完整资产+分镜闭环由 `manju-director-cn` 作为单一主入口承担。只有整体导演方案、复杂跨专业冲突或从创意到成片的统筹需求，才额外启用 `director-previs-cn`。任何情况下，同一场戏只保留一份正式分镜事实源。

## 1. 完整资产+分镜的强制阶段顺序

### 阶段 1：剧本事实锁定

- 读取原剧本，拆分场次、时间、地点、人物、对白、动作、因果、转场与情绪节拍。
- 标记原文明确、素材可证、必然推论、导演选择和未知；未知不能补造成剧情事实。
- 锁定本次用户要求的风格、画幅、时长、角色身份、不可修改项和交付范围。

### 阶段 2：资产需求总账（先盘点，不先批量生图）

为角色、服装、场景、固定设施、家具、关键道具、状态变体分配稳定 ID。记录来源、首次出现、使用场次、持有者/手别、尺寸依据、空间锚点、状态变体、依赖关系和审批状态。

这一步是需求盘点，不代表要先把所有道具图做完。凡是会决定空间布局的大型物件（会议桌、讲台、床、车辆、武器架等），必须先把占地/尺寸作为已知值或明确的代理尺寸写入场景基线。

### 阶段 3：场景空间基线先行（正式分镜前的硬门禁）

使用 `scene-realism-director-cn` 建立每个场景唯一的静态空间基线。至少锁定：

- `scene_id`、场景边界、墙体/门/窗、固定设施、家具与大型道具占位；
- 世界坐标/朝向基准、稳定锚点、通道、可通行区域、人物可站立/坐下/接触的支撑面；
- 主要机位区、可拍方向、轴线风险、遮挡关系和光源方向；
- 已知尺寸、估算尺寸、未知尺寸必须分开标记；没有测量依据不得伪造精确米数。

**最低可用证据**：用户已批准的场景参考，或一份可复核的俯视/布局图 + 关键视角图/白模 + 结构化场景数据。只有文字描述、没有可定位锚点时，不得标记空间基线已锁定。

场景空间基线状态使用 `SPACE_BASELINE_LOCKED`。未达到该状态，可以继续剧本分析和资产盘点，但不得进入正式逐镜分镜。场景改变时，必须重新检查受影响的走位、机位和镜头，不允许静默改布局。

### 阶段 4：角色与关键道具母版制作、绑定

空间基线锁定后，再制作/确认人物母版、服装、关键道具和状态变体：

- 每项资产使用稳定 `asset_id`，独立文件交付；拼图、宫格或展示板不能冒充可绑定的独立资产。
- 将角色初始位置、道具停放点、持有关系绑定到场景锚点。
- 对会改变空间占地的资产复核尺寸；若尺寸与代理值不同，先修订场景基线并重新锁定，再继续分镜。
- 角色形象、服装、发型、伤痕、道具状态和手别以批准母版为准，不因镜头提示词而漂移。

### 阶段 5：导演场面调度与预演

导演基于已锁定的场景和资产，确定场面目标、观众信息、人物目标、动作节拍、入场/离场路径、停留点、视线、反应和机位覆盖。人物路径、身体动作和摄影机路径分开描述。

简单正式分镜使用分镜 Skill 内置导演推演；复杂跨专业场面或完整导演方案才使用 `director-previs-cn` 额外统筹。

### 阶段 6：正式分镜编写

每镜必须能追溯到 `scene_id`、角色/道具 ID 和场景锚点。逐镜说明景别、机位、构图、人物世界位置、身体/头部朝向、视线、动作起点/过程/终点、道具状态、时长、声音和切镜承接。

- 世界坐标与画面位置分离；摄影机取景不得让人物瞬移。
- 原本相距较远的两人不得为了“双人近景”强行靠近；优先单人近景、画外人物、合法正反打或保持真实距离的中远景。
- 每镜开始状态承接上一镜结束状态；没有走位/交接事件，不得改变位置、持有者或朝向。
- 空间事实不明确时标记待确认，不得用提示词猜测补齐。

### 阶段 7：独立质检、修复与完整复检

按当前分镜独立自检规则逐镜检查：原剧本覆盖、场景拓扑、人物站位、动作因果、道具持有/可见性、服装与身份、轴线、视线、时长、摄影机可执行性和跨镜连续性。默认修复 P0/P1，修复最早冲突镜头并复查关联前后镜；重新输出完整修订终稿，再从头复检。

按风险运行 SCG、事件时间和骨骼接触校验器。结构校验通过不等于实际图像/视频生成通过。

### 阶段 8：镜头级资产补齐（在正式分镜之后）

正式镜头锁定后，按镜头清单补充单镜背景、特写参考、动作姿态、局部道具、特效层和系统 UI。不得在分镜前批量生成大量没有镜头用途的素材；也不得让后补资产反向改变已锁定场景事实。

### 阶段 9：视频、特效、剪辑与成片验收（按用户范围触发）

- 目标是代码驱动动画/MP4 时调用 `video-director-cn`；普通分镜不自动进入视频渲染。
- 需要粒子、HUD、系统 UI 时调用 `system-ui-vfx-cn`；需要专门运镜/打斗反馈时调用对应 Skill。
- 只有用户要求完整成片时才进入剪辑、声音、字幕、成片 QA；不因“资产+分镜”请求自动扩展到后期。

## 2. 必须阻断的错误

1. 未锁定场景拓扑就输出正式分镜。
2. 以镜头景别为理由移动人物世界坐标。
3. 以“同框”为理由把远距离人物瞬间拉近。
4. 道具无交接事件就换手、消失、出现或改变状态。
5. 用展示拼图代替独立资产文件。
6. 把文字审核、结构化校验、白模预演、真实生成和人工审片混为一个 PASS。
7. 用户只要求局部能力时，擅自启动完整制作链。

## 3. 统一交付清单

完整资产+分镜任务至少交付：剧本事实/未知清单、资产需求总账、场景空间基线（图像/白模/结构化数据及验收状态）、角色/服装/关键道具母版、导演调度要点、完整分镜终稿、独立自检与修复记录。视频、特效、剪辑与成片 QA 仅在用户明确要求时追加。

状态统一标记：`PASS`、`FAIL`、`BLOCKED`、`NOT_RUN`、`UNKNOWN`。没有真实证据的阶段不得标 PASS。
