# 剧本 → 导演预演 → 分镜：AI 知识调用执行卡

版本：V1.0.0
关联规范：[三级知识评级、晋级与调用规范](./三级知识评级与AI调用规范-V1.md)
评级数据：[知识资产评级登记表](./知识资产评级登记表-V1.json)

## 目标
用户提供剧本后，AI 按当前剧本条件调用评级最高且适用的知识，先建立可信场面，再完成导演预演和可执行分镜。

## 阶段一：剧本理解与事实锁定
- 提取原剧情顺序、人物关系、因果、台词意图、悬念和情绪变化。
- 保留用户指定的时长、风格、画幅、角色、场景和不可修改内容。
- 记录人物/道具初始状态与事件后的状态。
- 剧本没有交代的内容标记为未知，不擅自补成剧情事实。

## 阶段二：评级知识检索
1. 读取知识评级登记表。
2. 根据本场戏检索相关知识域。
3. 先选高级知识，再选中级；低级只在高/中级缺失或用户要求探索时作为候选。
4. 检查知识适用范围、来源版本、验证模型和限制。
5. 建立本场已采用知识/未采用知识/原因清单。

## 阶段三：场景与人物预演
1. 确定场景边界、门窗、墙体、固定设施、通道和功能区。
2. 确定家具、道具尺寸关系、支撑面和可通行区域。
3. 确定人物初始世界坐标、身体朝向、头部朝向和视线。
4. 将人物行动拆成起点、路径、终点、时间和关键姿态。
5. 检查多人路径冲突、接触、遮挡、支撑和动作因果。
6. 检查摄影机机位与运动，不能让镜头设计悄悄改动人物位置或轴线。

## 阶段四：导演预演
- 写清场面目标和观众需要知道的信息。
- 写清每个人物在场面的目标、动作和反应。
- 写清情绪节拍与关键事件。
- 写清场景调度、人物动线和镜头覆盖。
- 标记必须出现的画面、可省略内容、未知和高风险镜头。
预演先通过现实空间和动作因果检查，再考虑戏剧强化。不得为了迎合一句台词，把教室改成不合理布局或让人物瞬移。

## 阶段五：正式分镜
每镜至少写清：镜号、预计时长、景别、机位和构图；出镜人物、世界位置、身体/头部朝向、视线；动作起点、过程、终点及道具状态；台词、表演、情绪和观众信息；摄影机运动、焦点、轴线与切镜衔接；声音、特效和下一镜承接状态。

## 阶段六：独立自检与交付
按当前 main 的正式分镜编写和自检权威文件逐镜检查，修复 P0/P1 后重写完整终稿，再从头复检。根据使用情况运行 SCG、事件时长和运镜结构校验器。
最终分开标记：文本创作、结构/静态校验、白模或静态预演、真实图像/视频生成、人工/独立审片。没有实际生成与审片证据时，不得称为成片验证通过。

## 交付顺序
1. 剧本事实与导演意图；
2. 场景空间与人物站位基线；
3. 导演预演（场面调度/情绪节拍/关键动作）；
4. 正式分镜脚本；
5. 分镜独立自检及完整修订终稿；
6. 知识调用与评级说明；
7. 未验证事项和风险。
