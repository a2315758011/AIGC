# AI漫剧动态预演控制与生成服从性验证研究（第四批）

日期：2026-11-01  
主题：从导演台预演转向“导演意图是否进入成片”的可重复验证。  
证据分层：创作者自述实测、平台官方说明、同行评审/预印本研究、开源测试源码分别记录；不可把个人案例等同于独立复现，也不可把研究原型等同于普通用户可直接使用的产品。

## 一、本轮核心发现

### 1. 花叔：Updream 预演台完整实测
原文：https://www.huasheng.ai/insights/wechat-2247491605-1/  
作者：花叔 Alchain；文章日期：2026-08-17。

这是一份罕见的、含对照实验与失败反思的导演台操作记录。

**可复现操作链：**
1. 上传场景图，创建预演台并生成可单独选取的三维部件。
2. 关闭人物名牌，避免“人物1”等 UI 标签被录入参考视频。
3. 新建角色后，先设置正确的基础动作姿态（行走/跑步/坐姿等），再画整体空间路径；否则会出现站立姿态平移的滑行感。
4. 人物路径优先在顶视图绘制；复杂场景可切半透明显示，减少透视视图误选屋顶、柱子等错误平面。
5. 相机从当前构图创建机位；相机的“看向角色”在案例工具中是一次性设置，并非持续跟随。需要在路径各关键帧逐点设置看向。
6. 相机绘制路径可能受地面平面约束；升降（crane up/down）应使用具有XYZ高度的关键帧路径，不能假设平面手绘轨迹能表达高度变化。
7. 多机位通过时间轴分段安排；作者示例为15秒、30fps、4个机位，切点分别在0-4、4-8.5、8.5-12、12-15秒。
8. 导出“当前机位/当前轨道”监视器视频，而不是误导向视角；将白模视频与场景美术参考图分别接入视频生成节点。
9. 提示词明确素材职责：白模负责镜头切换时刻、机位高度、推拉运动、人物路径与速度；场景图负责美术风格、环境、材质、光线；白模中的灰白颜色和蓝色人形不应继承。
10. 文字镜头说明与白模时间线必须一致；明确人物身份、切点、硬切/转场要求。

**作者报告的对照实验：**
- 同一张场景图、同一段提示词，仅改变是否输入白模视频。
- 有白模组：人物经过哪根柱子、侧面跟拍速度、约3.5秒出画等时序接近预演。
- 无白模组：画面质量仍可接受，但模型自行改成近景，人物一直留在画面内，导演意图未达成。
- 多机位案例：作者报告15秒四机位案例中，最大切点偏差不到一帧；其他案例声称一次出片。
- 以上均为作者自述实验，非独立第三方复现；当前未取得原始项目文件/视频帧做本地量化复核。

### 2. 何时需要预演，何时不值得
花叔给出的实践边界：
- **建议预演**：人物与镜头存在相对运动（跟拍、环绕、穿越）；人物需沿特定路径并在指定时刻到位；镜头需要升降；同一场景多个机位之间空间关系必须成立。
- **通常不必预演**：单人简单说话、产品特写旋转等低空间复杂度镜头。
- **可能不适合**：光影本身就是主体的抽象镜头，白模可能增加流程成本而不带来明显收益。
- 这是创作者的经验建议，应在不同工具和模型上做成本/收益测试，不能当作普遍定律。

## 二、平台官方手册补充：参考素材映射与复杂度上限

小云雀 Seedance 2.5 官方手册：
https://xyq.jianying.com/tutorials/seedance-2-5

官方说明：
- 3D导演台支持角色动作库、机位运镜库、构图复刻、按帧时间轴、轨迹绘制和动态参考视频。
- 官方建议音视频主体1-5个较稳；主体图1-8个较稳；主体音视频参考5-10秒效果较好。更多主体或更长参考时稳定性可能下降。
- 图片/视频/音频数量上限不是推荐一次全部塞满；素材越多越要明确各素材的身份、角色与用途。
- 参考素材按上传顺序编号（图1、视频1、音频1），每个素材明确“参考什么/不参考什么”；例如视频1只参考动作，视频2只参考镜头运动，图片1只参考美术。
- 若白模已经清楚表达动作和运镜，提示词可直接准确指代视频1，避免写一段与视频内容矛盾的重复动作说明。
- 时间戳建议连续覆盖，避免中间空档；单段内容过少可能让模型自由发挥，内容过多则可能过度剪切或遗漏。
- 官方建议白模渲染提示词需明确是否参考白模的光影；若只参考动作和运镜，就明确不继承白模外观和光影。
- 这些属于官方使用建议，并非对所有场景的成功率保证。

## 三、学术研究：把导演意图变成可检查、可迭代的控制量

### 1. FilmFlow: Agentic System for 3D Virtual Film Cinematography
论文：https://arxiv.org/abs/2610.30753  
日期：2026-10-22。

重要方法：
- Interpreter：把自然语言/参考视频解析为场景对象关系、镜头意图、时长和目标主体。
- Scout：搜索合适的初始机位。
- Director：将复杂运镜拆成多个可执行的原子操作，并允许平移、旋转、构图、焦距等通道在时间上并行。
- Critic：把渲染结果与脚本/参考视频逐时间戳比较，给出具体问题和修订意见；计划需先通过碰撞与执行合法性硬检查，再做视觉质量评估。
- 论文提出 CinemaBench：150个Blender场景、750条文字控制任务、部分任务配有60段参考视频。

对 AIGC 的采纳：
- 镜头控制不能只写“环绕/推进”；要拆成相机位置、朝向、焦距/构图、开始/结束时刻等原子通道。
- 每轮修订必须说明哪一项偏离了指令，不能笼统说“效果不好”。
- 建立“硬约束先验收、画面美感后评分”的两层门禁。
- 已通过的镜头示例要连同场景、指令、执行计划和验收证据保存；不能只存一张好看的成片。

### 2. Generative Cinematographer (GenCine): Composing Camera and Object Motion in 3D
论文：https://arxiv.org/abs/2610.02180  
日期：2026-10-01。

重要方法：
- 从单张图像建立可编辑3D场景支架。
- 相机路径与前景对象运动在同一世界坐标系中共同设计。
- 为前景控制点分配跨帧固定身份标识，并使用背景XYZ、前景XYZ和身份图表达“背景没动、相机在动、人物相对世界在动”。
- 通过控制图向经过适配训练的视频模型传递空间/运动约束；不是把普通提示词自动变成几何硬约束。

对 AIGC 的采纳：
- 每个角色需要跨帧稳定的身份ID，不只靠“左边的人/蓝色衣服”描述。
- 相机运动和角色运动要共享同一场景参照系；否则相机环绕时人物相对背景的位置可能被误解。
- 人物局部动作（手臂、头部）与根节点整体移动可分开定义；高精度控制系统可用多个局部控制点表达非刚性动作。
- 当前 AIGC 的常规提示词/白模流程没有实现论文中的XYZ/身份控制图，不得宣称已具备同等能力；论文仅作为未来控制接口设计参考。

## 四、升级后的导演意图验证方法

### A. 两组对照，必须控制变量
- A组：场景参考图 + 角色参考图 + 相同文字提示词，不输入白模动态参考。
- B组：相同场景图、角色图、文字提示词和生成设置，额外输入白模动态参考。
- 除白模引用外，其他输入、时长、画幅、模型、清晰度、提示词、采样设置保持一致。
- 每组至少3次生成，尽量固定可固定的随机参数；若平台不暴露随机种子，记录任务ID、时间和全部输入。
- 不能用A组一条失败、B组一条成功就得出稳定结论；报告样本数、失败样本和成本。

### B. 统一测试镜头（先易后难）
1. **单人直线路径**：从门口走到桌边，明确起点、终点、速度、停步时间；检查是否站姿滑行、脚底滑动、是否准时到位。
2. **单人绕障碍**：绕过桌椅/柱子，不穿模、不穿过障碍物，保持合理步态。
3. **双人交汇**：两人迎面走来、停在指定距离，检查是否错边、重叠、擦肩错误。
4. **三人打断**：第三人从指定方向进入，停在指定位置，不替换身份，不让原有两人无故移动。
5. **人物出画**：在规定时间离开画面，后续镜头保持空场；检查模型是否擅自让人物重新入画。
6. **相机升降+前进**：同一时段改变相机高度与前进距离，检查是否只平推不升降。
7. **相机环绕+人物移动**：两条轨迹同时发生，检查人物相对场景的位置、身份与遮挡关系。
8. **四机位连续剪辑**：记录每个切点、人物末态/下一镜初态、轴线、景别和道具状态。

### C. 每条视频的评分维度（0-4）
- 角色身份稳定；
- 世界空间位置/路线符合；
- 到位时间与停留时间符合；
- 身体动作与根节点位移匹配；
- 脚底接触/支撑脚无明显滑步；
- 避障/接触关系成立；
- 摄影机轨迹、升降、注视点符合；
- 切点/末态连续；
- 场景美术与白模素材职责分离；
- 画面可用性与叙事清晰度。

每项必须附时间戳/帧号证据；不得只打总分。硬性错误（角色身份交换、穿墙、明显瞬移、切镜世界位置跳变）单独记录，不得被美观分抵消。

### D. 结果指标
- 导演意图服从率：满足硬约束的镜头数/总镜头数。
- 关键事件时间误差：成片动作/切点与预演的帧差。
- 轨迹偏差：人物在场景关键参照点（门、桌角、柱子、楼梯口）的偏移。
- 角色漂移率：身份、服装、体型、人数变化的发生比例。
- 动作瑕疵率：脚滑、站姿平移、穿模、错步、漂浮的出现次数。
- 返工成本：每条有效镜头生成次数、积分/费用、人工修订分钟数。
- 不能把视觉美感、生成质量和导演意图服从合并成一个分数。

## 五、白模素材职责模板

每次上传多个参考素材，按真实上传顺序逐个编号：

- 视频1（白模预演）：只控制角色ID对应、角色世界空间位置/移动路径/动作时序、机位路径/高度、镜头运动、切点时间。除非明确指定，不继承白模颜色、材质、人物外观、场景美术、UI标签。
- 图片1（场景参考）：控制建筑结构、空间布局、家具、材质、光线和美术风格；不覆盖白模中已确定的角色运动路径和机位时间。
- 图片2（角色A）：只定义角色A的脸、发型、服装、体型和身份；不改变角色B。
- 图片3（角色B）：只定义角色B；不改变角色A。
- 视频2（动作参考，可选）：只参考明确指定的动作；不得自动覆盖视频1的镜头路径。
- 音频1（对白/音色，可选）：只定义指定角色音色、台词和时间；不能重新分配角色身份。

如果实际上传顺序不同，必须按平台显示的真实顺序重排编号。禁止虚构“图片1/视频1”。

## 六、工具操作防错规则（来自创作者实测）
- 先确认人物基础姿势，再绘制路径；走路/跑步/坐下等动作必须匹配实际位移。
- 顶视图用于地面路径，透视视图用于最终构图；不要在透视视图误选屋顶/柱顶作为地面。
- 关闭白模人物名牌/辅助标记，避免录入视频。
- 相机“看向主体”可能只是一次性定向；逐个路径关键帧核对注视点，确认是否持续跟随。
- 升降运镜必须验证高度通道是否有效；如果路径工具只在地面平面绘制，应使用3D关键帧。
- 多机位录制前确认导出的是当前相机监视器画面，不是导演视角。
- 生成前抽查白模视频的首帧、中间关键帧、每个切点、尾帧；确认没有错误姿态、遮挡、UI标签或不合理穿模。

## 七、工具选择与成本判断
- 简单单人说话、静态特写：优先场景图+角色图+短提示词，不强行增加白模预演。
- 明确路径、相对运动、多机位、升降、穿越：优先先做动态预演。
- 白模制作时间与正式生成成本应分别统计。创作者报告白模预演本身不消耗视频生成积分，但不同平台的收费规则可能变化，需以账户实时页面为准。
- 花叔文章中15秒720P案例报告消耗3525积分，仅是该作者当时该平台的个人记录，不可当作现行统一价格。

## 八、证据边界与未完成验证
- 花叔案例含单镜头对照和多机位成片自述，证据价值高于纯口播，但仍是作者自测；本轮未下载原始视频和工程逐帧复核。
- 小云雀官方手册明确推荐素材映射和主体数量/时长范围，但这是官方建议，不能推断所有模型、所有账号、所有场景同样有效。
- FilmFlow 与 GenCine 是学术系统/研究方案，部分方法依赖专门训练或三维场景，不是现成的免费提示词技巧。
- 当前没有获得用户的视频模型账号/生成入口授权，也没有本轮生成的A/B视频；所以对目标模型的服从率仍为“未验证”，不能报告实测成功率。
