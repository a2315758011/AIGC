### 代码/测试静态审查

本轮读取了以下实现与测试源码，**没有克隆、安装依赖或运行 npm test/build**：

1. `src/editor/schema/routeTiming.ts` 与 `routeTiming.test.ts`
   - 轨迹按物理距离分配时间，而不是按路线点数量。
   - 中间通过点不应无故减速；显式停留点可设置 hold 时间。
   - 支持 uniform/soft/custom 速度模式和曲线弧长采样。
   - 测试明确覆盖这些行为。

2. `src/editor/schema/pathCollision.ts` 与 `pathCollision.test.ts`
   - 开启碰撞时将人物约束到地面高度，并将人物/相机推出静态障碍物范围。
   - 关闭碰撞时保留作者原始位置。
   - **实现限制**：障碍物范围使用简化包围盒；只纳入可见、无运动路径的 prop/scene 对象；人物平面避障主要在XZ平面处理。这不等同于完整刚体物理，也不能证明动态障碍、楼梯、门扇、复杂曲面和多人互相避让都已解决。

3. `src/editor/runtime/semanticBodyTracking.ts` 与 `semanticBodyTracking.test.ts`
   - 将 Mixamo、UE4 等不同骨骼命名映射为统一语义身体部位（头、胸、腰、手、脚等）。
   - 支持用户手动骨骼映射优先于别名回退。
   - 测试覆盖不同骨骼别名、父节点旋转后的世界坐标、场景隔离和手动映射。
   - 价值：摄影机可以跟踪“右手/头部/胸口”，而不只跟踪人物根节点。

4. `src/editor/runtime/cameraBodyTracking.ts` 与 `cameraBodyTracking.test.ts`
   - 摄影机可跟随动画中实时变化的身体部位世界坐标。
   - 支持 immediate/smooth 跟随及稳定化处理，避免目标抖动或突然跳变。
   - 测试覆盖挥手时右手目标变化与平滑跟随。

5. `src/experiments/routeAction/routeActionComparison.test.ts`
   - 对比独立视图中的角色路径位置和骨骼姿势。
   - 检测动作保持期间手相对腰部的偏移，帮助识别姿势异常。
   - 这是实验模块测试，不等于完整产品端到端验证。

### 对 AIGC 的新增采纳
- 轨迹速度必须按空间距离与停留点定义；相同路线不能因控制点数量不同而改变速度。
- 角色ID应映射到具体角色资产；必要时还要映射到语义骨骼部位。
- “跟踪角色”与“跟踪角色右手/头部”等是不同镜头控制能力。
- 静态障碍避让必须写清边界，不能将包围盒推离称为通用物理仿真。
- 站位图与动态轨迹必须共用同一空间基准，镜头跟踪读取动画后实时世界坐标。
- 自动化测试存在，只证明作者写了相应断言；没有实际运行不能说通过。

| 方法 | 当前评级 | 依据 | 使用范围 |
|---|---|---|---|
| 俯视线框图 + 简短身份提示 | 中 | 创作者公开视频标题/说明 | 多人初始站位、轴线 |

| 路径按距离分配时间、显式停留 | 中高 | 开源实现+自动化测试源码 | 动态轨迹设计 |
| 语义骨骼跟踪与平滑跟随 | 中高 | 开源实现+自动化测试源码 | 特写/跟拍设计 |

| 全景背景直接保证空间准确 | 低 | 用户反馈存在畸变/背景错位 | 不可直接采纳为保证 |

## 四、对现有导演技能的修订建议

1. 静态站位图至少标注：场景坐标原点、前/后/左/右方向、人物ID、脚印/身体朝向、视线、门窗/家具参照、摄影机轴线。
2. 每个镜头同时保存俯视调度图与最终机位构图图；俯视图负责空间，机位图负责画面投影。
3. 提示词先映射角色身份，再描述动作和表演；若参考图已清楚表达站位，不要用另一套文字左右关系覆盖它。
4. 全景图转换后检查：地平线、门窗垂直线、墙角连续性、家具尺度和隐藏面；存在明显畸变时改用正交俯视图/多视图，而不是继续叠提示词。
5. 动态路径记录控制点、距离、时间、停留和朝向；中间点不得意外停顿。
6. 摄影机跟踪目标要写清根节点还是身体部位；跟踪身体部位时验证模型骨骼映射正确。
7. 避障分级：静态包围盒避障、地面贴合、角色-角色避让、动态障碍、楼梯/门槛分别验收，不可合并为“碰撞已解决”。
8. 每个新方法按“来源证据→规则草案→对照测试→通过后升级强制规则”处理。

## 五、下一轮可执行验证

用同一段校园三人对话场景，做三种空间参考对照：
- A：只用文字描述人物站位；
- B：俯视线框图 + 角色身份映射；
- C：俯视线框图 + 角色身份映射 + 3D导演台机位/动态预演。

所有组使用同一场景图、角色图、提示词主体、模型、时长与画幅；每组至少3次生成。逐项检查：左右/前后关系、人物身份、桌椅通道、进入方向、停步位置、视线、轴线、镜头景别、背景畸变。分别报告服从率和返工成本，不凭单次出片定结论。
