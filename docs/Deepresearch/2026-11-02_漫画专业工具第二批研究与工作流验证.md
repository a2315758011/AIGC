研究日期：2026-11-02  
范围：漫画生产一体化、ComfyUI 页面编辑、网漫/分页排版、阅读性验收、英文排字、零成本路线。  
原则：只记录可从源码/文档核对的能力；项目作者自述的测试和演示必须标记为自报，未在本机运行不得标为实测。

## 一、第二批候选项目

### A. TT_AutoManga — 当前最值得优先做隔离试验的 AI 漫画流水线
- 地址：https://github.com/TTDiang2/TT_AutoManga
- 许可证：MIT；已读取仓库 LICENSE。
- 默认分支：master；仓库元数据更新时间：2026-10-28。
- 主要结构：故事/章节→故事板→每格提示词→SwarmUI 出图→页面组装→对白/旁白/SFX 排字→PDF/ZIP。
- Agent 接口：README 声称 28 个 MCP 工具、30 个 REST 接口和 CLI；页面预览工具可返回图像供 Agent 视觉验收。
- 专业方法价值：
  1. 先做 beat sheet（剧情节拍表），再从节拍拆格；不是先凑格数。
  2. 新场景/新时间先定场；首次出现角色要有可识别介绍；每格只承载一个主要叙事节拍。
  3. 角色外观字段要明确到颜色、长度、服装和头饰；重复角色并排检查；每格明确人物数量，避免克隆角色。
  4. 图像中预留气泡留白；模型不负责最终文字。
  5. 每页渲染预览后必须看图；检查读者理解、气泡遮脸、文字溢出、尾巴归属、人物一致性、解剖和时代物件。
  6. 局部画格修复后只替换对应画格，避免重建页面导致已排字内容丢失。
- 作者自述：129 项后端测试通过；这不是本机独立测试结果。
- 风险：需要 Python 3.10+、Node 20+；图像生成默认需 SwarmUI 本地服务。README 说明可配置任意兼容 LLM，文本步骤可选；实际图片生产仍依赖可用图像后端。免费 API 有额度/速率限制，不等于无限免费。
- 采纳等级：高（工艺方法与接口设计）；工具本机运行 NOT_RUN。

### B. ComfyUI Comic Creator — 页面级图像与出版编辑器
- 地址：https://github.com/ketle-man/comfyui-comic-creator
- 许可证：MIT；已读取 LICENSE。
- 默认分支：master；仓库元数据更新时间：2026-11-01。
- 能力：作品/页面管理、导入 SVG 格框模板、面板变形/拆分、图像/矢量/文字/气泡/形状图层、字体管理、绘画层、可编辑 SVG、PDF/EPUB/PNG/JPEG/WebP 批量导出、项目备份恢复。
- 采纳：将批准画格导入页面编辑器；格框/文字/气泡独立图层；保留可重编辑 SVG；导出时按物理尺寸和 DPI 计算像素，不把页面预览当成印刷文件。

## 二、与第一批研究合并后的推荐分工

- 主流程编排/读者理解/逐格 QC：TT_AutoManga 的 craft playbook（方法采纳，不默认替换本仓库现有工作流）。
- 角色/服装/世界状态版本：OpenManga 的版本状态与连续性数据模型。
- 逐格人工批准/锁定字段/局部返工：agent-comic-kit 的流程。
- 角色与场景透视：需要时使用现有 AIGC 角色/场景事实；有复杂空间冲突时再用 Blender 白模，不强制每格 3D。
- 页面编辑、分格和可编辑矢量：ComfyUI Comic Creator；轻量替代 WakuWaku。
- 气泡和对白排字：优先独立矢量/文字层；复杂排字再评估 Manga Typesetter / Sloom Studio / Manga Editor Desu。
- 旧图去字：manga-text-removal 的 CTD→人工审掩码→LaMa→OCR→人工放大检查流程。
- 输出：网漫与分页版分别布局；统一源画格、对白数据和资产状态。

## 三、针对欧美彩色商业漫画的必要修正

部分外部项目主要面向日漫、黑白漫画或 CJK 竖排。不能直接把它们的默认规则搬到欧美彩色漫画：
- 欧美英语漫画一般按 LTR（从左到右）阅读；每页气泡顺序必须按实际页面视觉流检查。
- 英文对白的字数、气泡宽度、字体大小和行长必须以手机/目标印刷尺寸复核。
- 不能将 CJK 竖排列长、日漫右到左顺序、黑白网点、日式拟声字形当作欧美彩色漫画默认值。
- 欧美彩色漫画需要独立验证色彩连续性、肤色、服装色、场景色温、阴影方向和跨页调色。
- 不能因为外部工具支持 EPUB/CBZ/PDF 就推断符合某个平台的具体上架尺寸、文件限制或内容规范。

## 五、实测优先级与停止条件

1. **先对 TT_AutoManga 做源码隔离检查和轻量启动评估**：检查依赖、配置默认值、MCP 工具权限、图片/文件写入路径、删除接口、路径穿越、API key 掩码和测试入口。未确认目录隔离前不得接触正式漫画项目。
2. **再评估 ComfyUI Comic Creator**：当前工作站 ComfyUI 是否存在/运行、版本是否兼容；优先只读检查，不安装额外模型。
3. **用 WakuWaku / SceneCraft 做无密钥轻量页面排字验证**，检查保存/导出尺寸、SVG/PDF 是否真实有效。
4. **manga-text-removal** 独立测试：只使用明确授权的测试画格；源图只读，输出到隔离目录；OCR 残字与伪影检查。
5. 每个项目最多进行一次环境适配和一次修复重测；遇到依赖缺失/权限不足/维护风险时停止，不循环安装。
6. 只有真实测试通过的工具才可标记 VERIFIED；作者 README 自报的测试只能标 SELF_REPORTED。
