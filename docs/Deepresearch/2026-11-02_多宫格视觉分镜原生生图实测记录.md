# 多宫格视觉分镜：GPT 原生生图实测记录

日期：2026-11-02  
任务：评估 GPT 原生生图直接生成 4/9/25 格联系表时的表现，并判断是否能替代独立画格生产 + 程序排版。

## 1. 实际结果

本轮图像生成共取得三份整图样本：

| 样本 | 模型输出 | 是否为独立画格文件 | 结论 |
|---|---|---|---|
| A | 5×5 / 25格咖啡广告联系表 | 否，单张合成图 | 仅整图草案 |
| B | 3×3 / 9格咖啡广告联系表 | 否，单张合成图 | 仅整图草案 |
| C | 5×5 / 25格保温杯广告联系表 | 否，单张合成图 | 仅整图草案 |

三个样本都包含画格边框、镜号/文字标注与多镜头拼图。它们可用于观察模型对宫格整体构图、节奏和广告视觉风格的理解，但不能作为独立画格输入排版器，也不能证明镜号、时间码、产品文字准确。

## 2. 发现的问题

1. **文本精度不可靠**：生成式图像中的镜号、时间码、品牌名、产品卖点可能出现错字、重复或时间区间不连续。
2. **源文件不可独立返工**：整张图是单一图像，单格返工和版本对比困难。
3. **缺少结构化镜头事实**：画面无法直接证明每格对应的权威镜头 ID、原剧本来源、SCG 状态或参考资产。
4. **质量审核被压缩**：联系表整体观感可能掩盖单格人物、手部、道具、空间和动作错误。

## 3. 决策

- 保留“直接生成整张宫格”作为概念草案/A-B 对照路线，明确标记 `WHOLE_SHEET_DRAFT`。
- 正式生产采用“独立画格生成 → 逐格审核 → manifest 锁定镜头顺序 → 程序生成联系表”。
- 镜号、时间码、标题、品牌文案由程序或排版层添加，不依赖图像模型绘制。
- 不把整图裁切后的面板冒充独立生成画格；若仅为版式演示而裁切，必须标记 `DERIVED_CROP`，不能进入正式画格资产库。
- 当前 GPT 原生生图的逐格生成行为尚未验证；本轮没有成功得到一组独立镜头文件，因此独立画格生产状态为 `NOT_RUN`，不是 PASS。

## 4. 下一轮判别实验

1. 选择已有批准的角色/场景参考与真实镜头清单，避免另造剧情事实。
2. 对同一镜头逐一提交独立生成请求，强制每次只输出一个 16:9 画面，不要联系表、拼图、分栏或文字。
3. 保存每个单镜头原始图像，记录生成模型、请求参数、图像 ID、角色/场景参考版本。
4. 由分镜导演与场景真实性技能逐格检查，再用排版工具生成联系表。
5. 与整图生成样本对照：人物一致性、场景恒常性、镜头准确度、文字准确性、返工成本与可追溯性。
