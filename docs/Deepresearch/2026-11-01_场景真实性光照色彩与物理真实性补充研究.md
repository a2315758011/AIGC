# 场景真实性补充研究：光照、色彩、物理效果与物体级真实感

日期：2026-11-01  
目标仓库：a2315758011/AIGC  
关联技能：skills/scene-realism-director-cn/  
状态：官方论文/作者仓库已核对；已形成采纳规则；本轮不安装模型、不下载大型数据、不提交生成任务。

## 1. 本轮结论

“AI 场景有点假”除了空间拓扑，还常见四类视觉问题：

1. 光照不可信：主光源方向、颜色、亮度分布、阴影和反射不能互相解释。
2. 颜色过度生成化：饱和度、局部对比度和色彩分离被夸张，画面像套了滤镜。
3. 物理编辑不完整：增加/删除/移动物体后，阴影、反射、折射、接触和周边状态没有同步变化。
4. 物体局部不真实：整体场景看起来正确，但单个物体的形状、表面纹理、边缘和材质不可信。

真实性评估必须同时包含全局场景、物体局部、光度/颜色和物理编辑效果，不能只评空间关系或整体美感。

## 2. 一手论文与作者仓库

### 2.1 Shedding Light（2026）：生成模型是否真正理解光照

- 论文：https://arxiv.org/abs/2609.10787
- 作者项目页：https://lvsn.github.io/SheddingLight/
- 官方仓库：https://github.com/JustineGiroux/SheddingLightBenchmark
- GitHub 仓库许可：MIT。
- 官方 README：评测 16 个生成模型；项目基准头部说明覆盖 1,006 个室内场景；其底层 Multilum 数据集介绍为 1,016 个室内场景、每个场景 25 个经过标定的光照方向。两个数字口径不同，引用时分别注明，不混写为同一统计量。
- 方法：在真实室内照片的遮罩区域中生成灰色漫反射球和镜面探针，再从探针反推光照方向、颜色与辐射分布；以光照方向角误差、Delta E 色差、辐射分布 KL 散度等指标对照真实标定值。
- 数据资源：GT、遮罩与预计算结果约 220 MB；三种开源模型的完整生成图像子集约 122 GB。完整生成图并非运行基础评估所必需。
- 环境：Python 3.9+；可选依赖包含 Diffusers/ComfyUI；若自行执行模型补绘需要 GPU。
- 采纳：
  1. 把主光方向、光源颜色、光照分布、反射高光分开检查。
  2. 对需要客观光照验证的场景，优先借鉴真实光探针/已知光源方向的评测思路，而不是只问 VLM“光影自然吗”。
  3. 仅借鉴评测设计；不下载 122 GB 数据集，不在工作站安装其完整依赖。
- 边界：该基准主要验证在真实照片中补绘探针时对光照的理解，不等同于完整室内场景文生图的全部真实感评测。

### 2.2 Too Vivid to Be Real? / CFM（CVPR 2026 Highlight）：颜色过艳会降低真实感

- 论文：https://arxiv.org/abs/2603.10990
- CVPR 官方论文页：https://openaccess.thecvf.com/content/CVPR2026/html/Fang_Too_Vivid_to_Be_Real_Benchmarking_and_Calibrating_Generative_Color_CVPR_2026_paper.html
- 作者项目页：https://zhengyaofang.github.io/CFM/
- 官方仓库：https://github.com/ZhengyaoFang/CFM
- 许可：Apache-2.0。
- 官方项目页说明：Color Fidelity Dataset（CFD）由约 189,490 组图构成，每组包含 1 张真实照片和 6 张合成变体，总计约 1.33M 张图；CFD-Human 包含超过 20,000 条人工评分，覆盖 6,690 张图，平均标注者间 Spearman 相关系数超过 0.85。
- CFM 使用 Qwen2-VL 视觉语言骨干评估颜色忠实度；论文指出传统审美/偏好指标可能偏好高饱和、高对比的图像，即使这些图并不更接近真实摄影。
- CFR 是无需训练的颜色真实性修正路线，通过调节扩散引导强度改善颜色忠实度；它不是一个通用“降低饱和度”滤镜。
- 运行门槛：作者 README 推荐 Python 3.11、PyTorch 2.5.1 和独立环境；发布 CFM-7B 权重。完整评估模型不属于轻量默认依赖。
- 采纳：
  1. 新增颜色真实性维度：整体饱和度、局部色彩夸张、白平衡、色温关系、曝光与高光剪切。
  2. 审查过艳、过 HDR、暗部压死、亮部发白、各物体色彩过度分离等问题。
  3. 不默认全图降饱和；先判断是光源色温、材质反射、曝光、白平衡还是模型色彩偏置。
  4. 若目标生成平台不暴露 CFG/采样参数，不能声称已执行 CFR；只能把其作为研究参考。
- 边界：CFM 分数用于颜色忠实度，不代表空间拓扑、建筑功能或整体摄影真实性。

### 2.3 PICABench / PICAEval（ICLR 2026）：物理效果不能只看主体是否改对

- 论文：https://arxiv.org/abs/2510.17681
- ICLR 官方页面：https://proceedings.iclr.cc/paper_files/paper/2026/hash/ae0509bfd3e0c2414164209949708e4e-Abstract-Conference.html
- 作者仓库：https://github.com/Andrew0613/PICABench
- 数据集：https://huggingface.co/datasets/Andrew613/PICABench
- README 将物理编辑拆分为 Optics（光学）、Mechanics（力学）、State Transition（状态变化）三个方向和八类规律。
- PICAEval 使用带区域框的人工标注问答，对局部编辑结果进行可判定检查；例如删除花朵时，不仅主体要消失，镜面反射中的花朵也应同步消失，花瓶、阴影和周边物体关系应保持合理。
- 执行门槛：官方 README 提供 GPT API 评测或 Qwen2.5-VL-72B/vLLM 评测路线；后者需要多 GPU 配置。GPT 路线会上传图片并产生 API 费用/隐私处理要求。
- 许可：GitHub 仓库 API 未返回可识别的仓库 LICENSE 元数据；未确认许可前不复制代码、数据或评测题。
- 采纳：
  1. 为添加/删除/移动/改变属性等局部编辑任务增加物理副作用清单。
  2. 逐区域检查阴影、反射、折射、遮挡、接触和非编辑区域是否被破坏。
  3. 借鉴区域级是/否问题，不直接依赖昂贵的 72B 评审器或外部付费 API。
- 边界：PICABench 是图像编辑物理一致性基准，不应把其分数直接当作文生图场景真实感分数。

### 2.4 Be More Specific（CVPR 2025）：物体级形状与纹理要分开看

- 官方论文页：https://openaccess.thecvf.com/content/CVPR2025/html/Liang_Be_More_Specific_Evaluating_Object-centric_Realism_in_Synthetic_Images_CVPR_2025_paper.html
- 研究把物体真实感拆为 shape（形状）和 texture（纹理）两部分，并建立对象级标注数据与 OLIP 评估模型。
- 采纳：物体近景验收不只检查类别是否正确，还要分别检查轮廓/结构、表面纹理、边缘细节和材质响应。场景全局正确不能抵消关键物体的形状错误。
- 边界：对象级评分不能替代整间房间的空间关系和物理功能验收。

### 2.5 ImagenWorld（ICLR 2026）：必须能解释错误发生在哪里

- 官方论文页：https://proceedings.iclr.cc/paper_files/paper/2026/hash/458fa8ee331566383d8e74bdb647f829-Abstract-Conference.html
- 规模：3.6K 组条件、20K 条细粒度人工标注，覆盖生成/编辑、多参考图和六类内容领域。
- 论文报告：部分 VLM 自动指标与人工排序相关性较高，但仍不足以提供细粒度、可解释的错误归因。
- 采纳：报告必须记录哪个物体、哪个区域、违反哪条规则、证据是什么，不能只给整体 1—5 分。
- 代码/数据许可：本轮未核实到可直接采用的官方代码与数据许可；仅采纳论文中的评测思想。

## 3. 对 AIGC 场景真实性 Skill 的具体改动要求

### 3.1 新增颜色真实性维度
- 饱和度是否符合真实场景与光源条件，是否出现全图高饱和。
- 是否存在不自然的局部色彩跳变、过强互补色、过度 HDR。
- 白平衡与主光源色温是否相容。
- 高光是否剪切成纯白，暗部是否无细节死黑。
- 材质本色、光源色和反射色是否被混为一谈。

### 3.2 新增光度真实性维度
- 明确主光源方向、颜色和面积/软硬。
- 投影方向与光源位置是否一致。
- 接触阴影是否对应真实接触位置。
- 镜面/金属高光是否与环境及观察角度相容。
- 透明物体是否有合理折射、厚度和背景变形。
- 只有在具备真实参考/标定条件时才使用方向角、Delta E、KL 等数值指标；普通单张生成图不可虚构这些数值。

### 3.3 新增物体级真实性维度
- 形状：轮廓、结构、连接、厚度和部件数量是否合理。
- 纹理：尺度、方向、重复频率、微表面变化是否符合材质。
- 局部：边缘是否融化、重复、粘连或被不自然锐化。
- 关键物体近景应单独放大检查，不用全景缩略图替代。

### 3.4 新增物理编辑副作用检查
对添加、删除、移动、替换对象的图像编辑：
- 删除物体时，同步检查其阴影、反射、折射、遮挡和接触关系是否消失/更新。
- 添加物体时，检查它对周边投影、反射、遮挡和支撑的影响。
- 移动物体时，检查旧位置残留、原阴影、反射和新接触阴影。
- 非编辑区域检查是否被无故改变；必要时使用掩膜外一致性对比。
- 将编辑区与非编辑区分开打分。

## 6. 推荐后续实验顺序

1. 先做静态场景 A/B：验证空间约束对教室/办公室结构的影响。
2. 再做光照专项：固定真实场景底图与光源条件，检查方向、色温、阴影和反射。
3. 再做颜色专项：固定内容和曝光设置，对照是否存在过饱和、过对比及白平衡偏移。
4. 最后做局部编辑专项：添加/删除/移动物体，检查光学与力学副作用、非编辑区域一致性。
5. 每个阶段独立记录缺陷，不将空间、光照、色彩、编辑变量同时更换后归因于某一项。
