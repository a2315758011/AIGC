# 漫画原文清理与排字工具第三批实测候选审查

审查日期：2026-11-02  
目标：为 MOONKEEP 第一话选择可本地运行、支持漫画气泡清理与可编辑排字的工具。  
范围：公开源码、官方简体中文说明、许可证、发布说明与本机连接状态。未安装、未启动、未改动本地工程。

## 结论

优先候选：**Carrot Manga Translator v3.8.3**。它是目前查到最贴近“漫画原稿 → OCR → 原文擦除 → 可编辑文本块 → PSD/图片导出”的桌面工作流。它支持 Windows 10/11，具有 AOT/LaMa/Flux 原文擦除、独立 Codex 图像设置、仿制图章/修复画笔、PSD 分层导出、原稿与修补结果分开保存，并有中文说明。

但本轮没有在用户电脑安装或运行。不能称为已接入或修复成功。

## 候选比较

### 1. Carrot Manga Translator
- 仓库：https://github.com/ucx0204/CarrotMangaTranslator
- 官方简体中文说明：https://github.com/ucx0204/CarrotMangaTranslator/blob/master/README.zh-Hans.md
- 当前 README 标示 v3.8.3，Windows 10/11。
- package.json：version 3.8.3；license GPL-3.0-only。
- 官方功能说明：OCR、原文擦除、嵌字与校对、PSD/PNG/JPEG/WebP 导出；本地 Gemma、Codex 或 OpenAI 兼容 API；AOT/LaMa/Flux 图像清理；仿制图章和修复画笔；原稿、擦除图、mask 分开保存；MCP 可用于外部 AI 应用查询/编辑/输出。
- v3.8.3 release notes：Windows x64 Setup EXE 当前未代码签名，提供 SHA-256 和构建来源记录。安装前需核对哈希与发布来源，不可将其描述为已签名软件。
- 许可证：GPL-3.0-only。允许使用和商业使用，但若分发其修改版/衍生程序需履行 GPL 对应源码及同许可证义务。仅将其作为独立工具处理自有漫画图像，与将代码合并进闭源商业软件是不同风险；不得把它的代码复制进 MOONKEEP 项目。
- 适用性：高（本地漫画清理、文字块编辑、PSD 工作流）。
- 限制：本机尚未验证；本地模型需要下载；部分 Codex/API 功能会联网，必须避免将原稿发送到未授权服务。

### 2. Lumina
- 仓库：https://github.com/lumina-tl/lumina
- 官网：https://lumina.navierr.dev/
- MIT 应用代码；Windows 桌面应用；检测、OCR、LaMa Manga/LaMa、排字都可在本地运行，翻译才可选外部 API。
- 支持可编辑的逐气泡 mask、文本块、单文件 .lmi 工程。
- 模型许可证独立于应用许可证；README 指出可选 rfdetr_seg 模型因训练数据限制仅供学术/非商业研究，商业用途必须禁用该模型并核查所用模型许可。
- 适用性：高（局部气泡 mask 和逐步编辑很符合本项目）。
- 限制：本机未安装；模型下载/实际重建质量未验证。

### 3. KŌMA Studio
- 仓库：https://github.com/klaus-2/koma-studio
- MIT；本地漫画 OCR、翻译、inpainting、typesetting、章节导出。
- 官方仓库说明 v1 Electron 版为 stable maintenance mode；v2 Tauri 版仍在开发中。
- 构建环境要求 Bun >=1.4、Node >=22.18、Python 3.12；不符合“直接轻量接入现有项目”的优先条件。
- 适用性：中高；可作为流程/工具备选，不优先部署。

### 4. IOPaint
- 仓库：https://github.com/Sanster/IOPaint
- Apache-2.0；支持 LaMa、PowerPaint、SD inpainting 等本地修复。
- 官方仓库已于 2025-08-13 归档，代码只读。虽然功能强，但维护状态不适合作为新生产线首选。
- 适用性：中；可作旧版备用，不优先部署。

### 5. Lama Cleaner
- 仓库候选：https://github.com/Mu-Gui/lama-cleaner
- 功能覆盖漫画气泡擦除、LaMa、Manga 模型和 CPU/GPU；但当前应优先验证 Carrot / Lumina 的可编辑漫画专用流程，不重复建设单一擦除服务。

## 对 MOONKEEP 的采用策略

1. 不将任何工具的自动擦除结果直接认定为合格。
2. 先用 Carrot v3.8.3 或 Lumina 对 P01 一处气泡做隔离试验；只处理气泡 mask 区域。
3. 必须输出：清理前、mask、清理后、mask 外差分图、人工 QA。
4. 通过后才批量处理其余气泡。
5. 用 PSD 或独立 SVG/PNG 文字层重新放入六句核实对白。
6. 保留原稿、clean plate、mask、lettering layer、合成图五种独立资产。
7. 禁止整页重绘；禁止模型改写对白；禁止把包扎场景加入 Episode 01。
8. 竖屏网漫与分页漫画必须分别排版，不能把长图简单裁成两页就称作正式出版版。

## 本轮失败的图像生成记录

本轮会话中的 GPT 原生生图连续返回了双页概念画面，出现包扎胸口剧情，与第一话“喷泉旁相遇”的六句对白流程不匹配。该输出明确 REJECTED，不进入素材库、不计进度。不得继续用自由生图冒充局部 inpainting。
